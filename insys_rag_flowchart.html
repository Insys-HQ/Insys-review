💡 실제 활용 예시

"2025년 매입자료 중 인텍코리아 건만 뽑아줘"
→
SQL 생성 → RDS 조회 → 인텍코리아 매입 전표 필터링 → 엑셀 다운로드 제공
"1분기 계열사별 매출 비교해서 요약해줘"
→
다중 SQL 병렬 조회 → 집계 → LLM이 비교 요약 + 차트 데이터 생성
"A업체랑 계약서에서 대금 지급 조건 찾아줘"
→
벡터 검색 → 계약서 PDF 관련 청크 추출 → LLM이 조항 요약 후 답변
"챈스 이번달 법인카드 사용내역 정리해줘"
→
카드내역 CSV → 파싱 → 챈스 필터 → 항목별 분류 요약 + 합계 반환
