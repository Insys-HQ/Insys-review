📡 1. RC-NET 시스템 개요 개요
RC-NET이란? 대한적십자사 서울지사 재난대응봉사회(NDRT)가 구축한 하이브리드 무선통신망입니다. YAESU FTM-510D + WIRES-X를 기반으로 C4FM 디지털·아날로그 FM·Zello PTT를 통합하여 재난 현장에서 끊김 없는 통신을 제공합니다.
🏢 DS0ARC — 신월동 기지국
  • HRI-200 탑재 → Room Host
  • C4FM + 아날로그 FM 게이트웨이
  • DTMF Node: 38182 / Room: 48182
  • 유선 인터넷 · UV Dual 3GP 안테나
🏢 HL0FRC — 서울지사 기지국
  • PDN 모드 (HRI-200 없음)
  • C4FM 디지털 중계
  • 유심 라우터 · UV Dual 3GP 안테나
🚐 DS0ARC/M — 이동통신 차량
  • PDN 모드 (HRI-200 없음)
  • 평상시 휩 / 비상시 3GP 안테나
  • 유심 라우터 · 차량 이동 운용
🔬 HL2TLS — 개인 테스트국
  • PDN 모드 (HRI-200 없음)
  • DTMF Node: 59043 / Room: 69043
  • 유심 라우터 · UV Dual 휩 안테나
💡 핵심 구조 모든 노드가 인터넷(WIRES-X 서버)을 통해 연결되며, DS0ARC(신월동)가 Room Host로 아날로그↔C4FM 게이트웨이 역할을 담당합니다.

📟6. 아날로그 모드 전환
아날로그 FM 모드는 DS0ARC(HRI-200 노드)에서만 지원됩니다. PDN 노드는 C4FM 디지털만 지원.
1
WIRES-X SW → Transceiver settings → Modulation 변경
File(F) → Settings(P) → Transceiver → Modulation → RX:FM – TX:FM 선택

Apply → OK

3
주파수 확인

🔁리피터 설정 — 아날로그 무전기 FTM-510D 연결
리피터(중계기) 구성 FTM-510D가 아날로그 FM 무전기 신호를 수신하여 WIRES-X 인터넷망으로 중계합니다.
1
DS0ARC HRI-200 노드 Portable HRI 모드 설정
File(F) → Settings(P) → Node settings → Style: Open (Portable HRI 모드 자동 활성화)
2
Modulation → AMS 설정 권장
AMS 모드: C4FM 수신 시 자동 디지털, 아날로그 FM 수신 시 자동 FM 전환
3
아날로그 무전기 주파수 맞춤
현장 아날로그 무전기를 FTM-510D 운용 주파수(145.620 MHz)로 설정
4
Squelch 설정
WIRES-X SW → Transceiver → Analog SQL → NoTone (스켈치 없이 수신) 또는 Tone SQL 설정
5
DTMF #55555 활성화 확인
General settings → DTMF #55555 체크박스 활성화 → 아날로그 무전기에서 원격 Room 접속 가능
🗣️아날로그 무전기 교신 방법
1
아날로그 무전기를 145.620 MHz로 설정
FTM-510D와 동일한 주파수로 맞춤
2
DTMF #55555 입력 → Room 접속
무전기 DTMF 키패드로 #55555 입력 → RCNet-Disaster Room(48182) 자동 접속
3
PTT 눌러서 교신
일반 아날로그 FM 교신과 동일. FTM-510D가 수신하여 WIRES-X로 전 거점 중계
4
교신 종료 → DTMF * 또는 #99999
Room 접속 해제
🔢7. DTMF 원격 제어 명령어
#55555 — 지정 Room 자동 접속

미리 지정된 기지국 Room에 즉시 연결. 긴급 시 우선 사용.
사전 설정: Call settings → Room ID에 48182 입력

#66666 — 노드 상태 조회

현재 노드 접속 여부·Room 정보를 음성으로 회신.

#99999 — 접속 해제

현재 Room에서 분리. 채널을 비워 타 사용자 사용 가능.

* — 접속 해제 (단축)

#99999와 동일 기능. 간편 단축 코드.

⚠️ 사전 설정 필수 File(F) → Settings(P) → General settings → DTMF #55555 체크박스 활성화 필요
