2신월동 DS0ARC 무선국 운용
역할: WIRES-X RCnet-DISASTER 룸 서버. HRI-200이 상시 인터넷에 연결되어 전 거점의 교신을 중계합니다.
노드국 기동 절차
  • 1
    PC 전원 ON → WIRES-X 소프트웨어 자동 실행 확인
    소프트웨어 하단 상태표시줄에 "Online" 표시 확인
  • 2
    HRI-200 전원 ON → 전면 LED 녹색 점등 확인
  • 3
    FTM-510D 전원 ON
  • 4
    WIRES-X 버튼을 3초 길게 누름 → 화면에 "WIRES-X" 표시 확인
    HRI-200과 연동되어 노드 모드 활성화
  • 5
    PC 소프트웨어에서 RCnet-DISASTER 룸 활성화 확인
아날로그 / 디지털 전환
ANALOG 아날로그 FM 모드

인근 봉사원 핸디와 로컬 FM으로 직접 교신

  • 1
    DX 버튼 → DIG/ANALOG 메뉴 진입
  • 2
    노브 돌려 FM 선택 → 눌러 확정
  • 3
    봉사원 핸디와 동일 주파수·CTCSS 확인
DIGITAL 디지털 노드 모드

HRI-200 경유 WIRES-X 룸 운영 (기본 운용 모드)

  • 1
    DX 버튼 → AMS 선택 (자동모드)
  • 2
    WIRES-X 버튼 3초 → 노드 활성화
  • 3
    PC 소프트웨어 룸 상태 확인
⚠️ 주의: 신월동 PC와 HRI-200은 24시간 상시 가동 유지. PC 재시작 시 WIRES-X 소프트웨어 자동실행 설정 확인 필수.
3마장동 HL0FRC 무선국 운용
역할: PDN(Portable Digital Node) 방식으로 신월동 룸에 접속. 인근 봉사원 핸디와 RF로 교신하며 전 거점에 중계합니다.
ANALOG 일반 아날로그 FM 교신

PC 연결 없이 FTM-510D 단독으로 로컬 FM 교신

  • 1
    FTM-510D 전원 ON
    PC 연결 불필요
  • 2
    DX 버튼 → FM 선택
  • 3
    마장동 봉사원 핸디 주파수 확인
  • 4
    PTT 눌러 교신
DIGITAL 디지털 리피터 모드 (PDN)

PC + 유심인터넷 연결 후 전 거점 중계

  • 1
    유심 라우터 전원 ON → 인터넷 연결 확인
  • 2
    FTM-510D 전원 OFF 상태에서
    DX 버튼 누른 채 전원 ON
    화면에 "WIRES-X PDN" 표시 확인
  • 3
    PC의 WIRES-X 소프트웨어 실행
  • 4
    Portable HRI 모드 선택 → RCnet-DISASTER 룸 접속
  • 5
    연결 상태 확인 후 운용 시작
⚠️ PDN 모드 제약: 룸 직접 개설 불가. 신월동 DS0ARC가 개설한 RCnet-DISASTER 룸 접속만 가능합니다.
4NDRT 이동통신차량 운용
역할: 현장 이동 중계국. 인근 봉사원 아날로그 핸디를 수신하여 WIRES-X 전 거점에 중계하거나, 직접 아날로그로 현장 교신합니다.
ANALOG 직접 아날로그 교신

차량 인근 봉사원 핸디와 로컬 FM 직접 교신

  • 1
    FTM-510D 전원 ON
  • 2
    DX → FM 선택
  • 3
    NDRT 권역 봉사원 주파수 확인
  • 4
    PTT로 교신
중계기 모드 PDN + 크로스밴드 리피터

봉사원 핸디(FM) 수신 → 인터넷으로 전 거점 중계

  • 1
    유심 라우터 전원 ON · 인터넷 확인
  • 2
    DX 누른 채 전원 ON → PDN 모드 진입
  • 3
    노트북 WIRES-X 소프트웨어 → RCnet-DISASTER 접속
  • 4
    A밴드: WIRES-X 주파수 (C4FM)
    B밴드: 봉사원 핸디 주파수 (FM)
  • 5
    Setup → CROSSBAND REPEAT → ON
    봉사원 핸디 PTT → 자동으로 전 거점 중계 시작
⚠️ 차량 전원 주의: FTM-510D는 반드시 10A 퓨즈 직결. 장시간 운용 시 차량 시동 유지 또는 외부 전원(보조배터리) 연결 권장.
5개인 야에수 디지털 무전기 보유 봉사원
대상: FTM-510D, FT-3D, FT-5D 등 야에수 C4FM 디지털 무전기를 개인 보유한 봉사원. WIRES-X에 직접 접속하거나 인근 무선국 경유로 교신 가능합니다.
방식 1 — 인근 무선국 주파수로 RF 직접 접속
  • 1
    가장 가까운 무선국(신월동·마장동·NDRT) 운용 주파수 확인
    → 주파수표 참조 (섹션 7)
  • 2
    DX → AMS 또는 DN 모드 선택
  • 3
    해당 주파수로 이동
  • 4
    WIRES-X 버튼 짧게 누름 → 접속 목록 표시
  • 5
    RCnet-DISASTER 룸 선택 → 접속 완료
  • 6
    PTT로 전 거점과 교신
방식 2 — 아날로그 FM 모드로 인근 무선국 경유
  • 1
    DX → FM 선택 (아날로그 모드)
  • 2
    인근 무선국 B밴드(FM) 주파수 맞춤
  • 3
    CTCSS 톤 동일하게 설정 → PTT 교신
WIRES-X 개인 등록 방법
  • 1
    https://www.yaesu.com/jp/en/wires-x/index.php 접속
  • 2
    New Member Registration → 이메일 입력 → 인증
  • 3
    무전기 Radio ID 입력
    무전기 Setup → 62번 RADIO ID에서 확인
  • 4
    등록 완료 후 메일로 Node ID · Room ID 수신
📌 참고: 개인 디지털 무전기도 WIRES-X 등록 없이 무선국 주파수에 맞추면 아날로그 FM으로 바로 교신 가능합니다.
6봉사원 아날로그 핸디 운용
대상: 일반 아날로그 FM 핸디 사용 봉사원. 담당 권역 무선국 주파수만 맞추면 바로 교신 가능합니다.

  • 2
