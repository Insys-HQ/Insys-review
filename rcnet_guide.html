2신월동 DS0ARC 무선국 운용
역할: WIRES-X RCnet-DISASTER 룸 서버. HRI-200 상시 인터넷 연결로 전 거점 교신 중계.
노드국 기동 절차
  • 1
    PC 전원 ON → WIRES-X 소프트웨어 자동 실행
    하단 상태표시줄 "Online" 확인
  • 2
    HRI-200 전원 ON → 전면 LED 녹색 점등 확인
  • 3
    FTM-510D 전원 ON
  • 4
    WIRES-X 버튼 3초 길게 누름 → 화면 "WIRES-X" 확인
  • 5
    PC 소프트웨어 RCnet-DISASTER 룸 활성화 확인
아날로그 / 디지털 전환
ANALOG 아날로그 FM

인근 봉사원 핸디와 로컬 FM 직접 교신

  • 1
    DX → FM 선택
  • 2
    봉사원 핸디 주파수 145.140 MHz 확인
  • 3
    송신톤 88.5 Hz 설정 확인
DIGITAL 디지털 노드 모드

HRI-200 경유 WIRES-X 룸 운영 (기본)

  • 1
    DX → AMS 선택
  • 2
    WIRES-X 3초 → 노드 활성화
  • 3
    PC 소프트웨어 룸 상태 확인
⚠️ PC와 HRI-200은 24시간 상시 가동. PC 재시작 시 WIRES-X 소프트웨어 자동실행 설정 확인 필수.
3마장동 HL0FRC 무선국 운용
역할: PDN 방식으로 신월동 룸 접속. 인근 봉사원 핸디(145.620 MHz)와 RF 교신 후 전 거점 중계.
ANALOG 아날로그 FM 교신

PC 없이 FTM-510D 단독 로컬 교신

  • 1
    FTM-510D 전원 ON
  • 2
    DX → FM 선택
  • 3
    145.620 MHz · 송신톤 88.5 Hz 확인
  • 4
    PTT 눌러 교신
DIGITAL 디지털 리피터 (PDN)

PC + 유심인터넷으로 전 거점 중계

  • 1
    유심 라우터 ON → 인터넷 확인
  • 2
    DX 누른 채 전원 ON
    화면 "WIRES-X PDN" 확인
  • 3
    WIRES-X 소프트웨어 실행
  • 4
    Portable HRI → RCnet-DISASTER 접속
⚠️ PDN 제약: 룸 개설 불가. 신월동 DS0ARC 룸 접속만 가능.
4NDRT 이동통신차량 운용
역할: 현장 이동 중계국. 봉사원 핸디(145.620 MHz) 수신 후 WIRES-X 전 거점 중계 또는 직접 아날로그 교신.
ANALOG 직접 아날로그 교신

인근 봉사원 핸디와 로컬 FM 교신

  • 1
    FTM-510D 전원 ON
  • 2
    DX → FM 선택
  • 3
    145.620 MHz · 88.5 Hz 확인
  • 4
    PTT로 교신
중계기 모드 PDN + 크로스밴드

봉사원 핸디(FM) → 인터넷 → 전 거점 중계

  • 1
    유심 라우터 ON · 인터넷 확인
  • 2
    DX 누른 채 전원 ON → PDN 진입
  • 3
    노트북 WIRES-X → RCnet-DISASTER 접속
  • 4
    A밴드: 436.140 MHz(C4FM)
    B밴드: 145.620 MHz(FM)
  • 5
    Setup → CROSSBAND REPEAT → ON
    핸디 PTT → 자동 전 거점 중계
⚠️ 전원: FTM-510D 10A 퓨즈 직결. 장시간 운용 시 시동 유지 또는 보조배터리 연결.
5개인 야에수 디지털 무전기 보유 봉사원
대상: FTM-510D, FT-3D, FT-5D 등 C4FM 디지털 무전기 보유 봉사원. WIRES-X 직접 접속 또는 아날로그 FM 경유 가능.
방식 1 — RF로 인근 무선국 직접 접속
  • 1
    가장 가까운 무선국 주파수 확인 → 주파수표 참조(섹션 7)
  • 2
    DX → AMS 또는 DN 선택
  • 3
    436.140 MHz 맞춤
  • 4
    WIRES-X 짧게 누름 → 접속 목록
  • 5
    RCnet-DISASTER 선택 → 접속 완료
  • 6
    PTT로 전 거점 교신
방식 2 — 아날로그 FM 모드 경유
  • 1
    DX → FM 선택
  • 2
    권역별 주파수 설정 (신월동 145.140 / 마장동·NDRT 145.620)
  • 3
    송신톤 88.5 Hz 설정 → PTT 교신
WIRES-X 개인 등록
  • 1
    https://www.yaesu.com/jp/en/wires-x/index.php 접속
  • 2
    New Member Registration → 이메일 인증
  • 3
    Radio ID 입력 (무전기 Setup → 62번 RADIO ID)
  • 4
    등록 완료 → 메일로 Node ID · Room ID 수신
6봉사원 아날로그 핸디 운용
대상: FM 아날로그 핸디 사용 봉사원. 권역 주파수만 맞추면 바로 교신 가능.
