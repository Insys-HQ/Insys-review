DS0ARC/M — 이동차량 PDN 노드
드라이버·프로그램 설치 및 설정 가이드

FTM-510D + SCU-58 + 노트북 PC + 유심 라우터 구성

문서버전 v1.0 작성일 2026-08-16 대상 DS0ARC/M (Node ID 127023)
구성 및 전제 조건
  • 리그: FTM-510D / 인터페이스: SCU-58 케이블 (HRI-200 사용 안 함)
  • PC: 노트북 / 네트워크: 유심(LTE) 라우터
  • 운용 방식: PDN (Portable Digital Node)
  • 공유기 포트포워딩·공인 IP 불필요 — 유심 라우터는 통신사 NAT 구조라 포트포워딩이 불가능하지만, PDN 방식은 이를 요구하지 않음
  • 목적: 재난 현장 출동 시 DS0ARC Room(48182)에 접속하여 현장 아날로그 무전기 사용자 연결

2

WIRES-X 소프트웨어 다운로드

  1. WIRES-X 로그인 페이지 접속 → DS0ARC/M 계정으로 로그인
  2. Node Owners Page 진입
  3. WIRES-X Software (zip 파일) 다운로드
  4. zip 압축 해제
참고 — PDN 방식에서는 HRI-200 장치 드라이버가 필요 없습니다. SCU-58은 리그 내부의 USB 인터페이스를 사용하므로, 드라이버는 리그 인식용으로 별도 설치됩니다(3단계).
3

USB 드라이버 설치 (FTM-510D 인식용)

  1. PC와 리그를 아직 연결하지 않은 상태에서 시작
  2. Yaesu 홈페이지에서 FTM-510D용 USB 드라이버를 다운로드하여 설치
  3. 설치 완료 후 안내에 따라 SCU-58로 PC와 리그를 연결
사전 확인 필요 — SCU-58 사용 시 필요한 드라이버 종류(리그 내장 USB 인터페이스용)는 Yaesu 사이트의 FTM-510D 다운로드 페이지에서 최신 버전을 확인하여 설치하십시오.
4

COM 포트 인식 확인

  1. 키보드 Windows + X → 장치 관리자 실행
  2. 포트(COM & LPT) 항목 펼치기 → 리그가 인식한 COM 번호 메모
  3. 사운드, 비디오 및 게임 컨트롤러 항목에서 리그의 USB 오디오 장치가 인식되는지 확인
인식 안 될 때 — 리그가 꺼져 있거나 PDN 모드로 부팅되지 않은 상태이면 COM 포트가 나타나지 않습니다. 6단계의 부팅 절차를 먼저 확인하십시오.
5

WIRES-X 소프트웨어 설치

  1. 압축 해제한 폴더의 Install.exe 실행
  2. [WIRES-X Software Setup] 클릭
  3. 라이선스 동의 → 설치 진행
  4. 설치 완료 후 PC 재부팅
PDN 방식 — [HRI-200 Device Driver Setup] 버튼은 클릭하지 않습니다. HRI-200 하드웨어가 없으므로 해당 드라이버는 불필요합니다.
6

FTM-510D를 PDN 모드로 부팅

  1. 리그 전원 OFF 상태에서 시작
  2. [DX] + [GM] 키를 동시에 누른 상태를 유지하면서 전원 ON
  3. 화면이 일반 VFO 화면이 아닌 Portable Digital Node 모드로 부팅되는지 확인
모드키 조합용도
Portable Digital Node (PDN)[DX] + [GM]DS0ARC/M 사용
Portable HRI (HRI-200 연동)[GM] + [DG3]DS0ARC 고정국용 (해당 없음)
키 조합 주의 — 전원을 켠 후에 키를 누르는 것이 아니라, 키를 먼저 누른 상태로 전원을 켜야 합니다.
7

WIRES ID Activation (노드 인증)

  1. 리그를 먼저 PDN 모드로 켠 후 WIRES-X 소프트웨어 실행
  2. COM 포트 선택 → 4단계에서 메모한 번호 지정
  3. WIRES ID Activation 창에서 입력
항목입력값
Serial/Radio ID자동 표시됨 (리그가 켜져 있어야 함 — 직접 입력 불가)
Node → DTMF IDDS0ARC/M의 DTMF Node 코드
Room → DTMF ID비워둠 (자체 Room을 개설하지 않으므로)

[ID Entry] 클릭 → CallSign / City / State / Country가 자동으로 채워지면 인증 성공 → [OK]

DTMF ID ≠ Node ID — Node ID(127023)와 DTMF Node 코드는 서로 다른 값입니다. Node Owners Page 계정 정보에서 DTMF 코드를 확인하여 입력하십시오.
Retry activation 금지 — File 메뉴의 Retry activation은 서버 등록 정보를 삭제하는 명령입니다. 인증 완료 후에는 절대 실행하지 마십시오.

DS0ARC Room(48182) 접속

방법조작
소프트웨어에서하단 Room 리스트에서 DS0ARC-ROOM2 (48182) 검색 후 접속
무전기에서DTMF 키패드로 #48182 입력
[Setup] 버튼 사용 금지 — Round QSO room settings 화면의 [Setup] → Room Active → Room Activation은 Room을 개설하는 호스트국(DS0ARC 고정국)만 수행하는 절차입니다. DS0ARC/M은 접속만 하므로 진행하지 않습니다.
11

현장 출동 시 운용 절차

  1. 차량 도착 → 안테나 및 리그 전원 확인
  2. 유심 라우터 전원 ON → 인터넷 연결 확인
  3. 노트북 PC 부팅 → 유심 라우터 Wi-Fi 연결
  4. 리그를 [DX] + [GM] 누른 채 전원 ON (PDN 모드)
  5. WIRES-X 소프트웨어 실행 → ONLINE 상태 확인
  6. Room 48182 접속 확인 (NET 표시등 녹색)
  7. 현장 대원에게 145.660 MHz / Tone SQL 88.5 Hz 설정 안내
