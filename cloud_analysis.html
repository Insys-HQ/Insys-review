재고·WMS 베어링 190종 입출고 ~2 GB Firestore / RDB 해당없음 중간 현재 Firebase 운용중
챗봇 벡터 인덱스 문서 임베딩 벡터 ~10 GB Vector DB (pgvector) 해당없음 낮음 RAG 검색 핵심
연구노트·특허 R&D센터 연구 기록 ~5 GB Document DB 주의 최고 영업비밀 보호 필요
출퇴근·GPS 로그 현장 위치 인증 기록 ~3 GB/년 TimeSeries / RDB 민감 중간 위치정보법 적용

07인시스 그룹 최종 추천 구성

🎯 추천 전략: NCP 메인 + AWS 연동 하이브리드 구성

Phase 1 · 즉시
NCP 기반 구축

NCP 서울 리전에 메인 서버·DB·Object Storage 구축. 인사·문서·WMS 데이터 이전. 챗봇 RAG 파이프라인 구성. 월 50~70만원 수준에서 시작 가능.

Phase 2 · 3~6개월
ERP API 연동

동생 AWS ERP와 REST API 연동. 인시스 NCP ↔ ERP AWS 간 데이터 브릿지 구성. 계정·권한 분리 유지하되 필요 데이터만 API 동기화.

Phase 3 · 6~12개월
AI 고도화

AI 비전검사 학습 파이프라인 NCP GPU 서버 또는 AWS Bedrock 연동. HyperCLOVA X 또는 Claude API로 챗봇 업그레이드. 자동 문서 생성 템플릿 완성.
