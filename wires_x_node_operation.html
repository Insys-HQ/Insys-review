FTM-510D WIRES-X 노드 운용 — 모드별 시작·검색·접속 정리

HL2TLS(Andy) 개인국 실전 정리 · 2026-08-14
v1.0 인시스 AI혁신 연구개발실
개요

FTM-510D(SCU-58 케이블, PC 직결)로 WIRES-X 노드를 운용할 때, 무전기를 어떤 모드로 켜야 하는지와 무전기 본체에서 룸/노드를 직접 검색·접속하는 방법을 정리한 문서입니다. 야에스 공식 "WIRES-X 포터블 디지털 노드 기능" 매뉴얼을 기준으로, 오늘 실전 확인된 내용을 반영했습니다.

핵심: 무전기를 PDN 모드(디지털 전용) 또는 포터블 HRI 모드(디지털+아날로그)로 켜고, WIRES-X 소프트웨어(ADMS-18 아님)를 실행하면, 무전기 자체 버튼으로도 룸/노드 검색과 접속이 가능합니다.
1. 무전기 모드별 켜는 방법
모드지원 범위켜는 방법화면 표시
일반 모드무전기 단독 (FM/디지털 교신)버튼 조합 없이 그냥 전원 ON평소 VFO(주파수) 화면
PDN 모드
(Portable Digital Node)		디지털 전용 인터넷 통신[D X] 키를 누른 채 전원 ON화면 하단 "WIRES-X PDN"
Portable HRI 모드디지털+아날로그 인터넷 통신[D X]+[GM] 키를 동시에 누른 채 전원 ON화면에 YAESU 로고 + "WIRES-X"
(소프트웨어 정상 통신 시 "WIRES-X NODE"로 표시)
💡
한 번 특정 모드로 켠 뒤에는, 무전기가 마지막 부팅 모드를 기억합니다. 이후 버튼 조합 없이 전원만 눌러도 같은 모드로 재부팅됩니다. 일반 모드로 되돌리려면, 마지막에 사용한 모드 진입 키 조합을 한 번 더 누른 채 전원을 켜면 됩니다 (토글 방식).
2. WIRES-X 소프트웨어 실행 및 연결 순서
1
PC 먼저 켜기

SCU-58 케이블이 무전기·PC 양쪽에 연결된 상태 확인. 이 단계에서 무전기는 아직 꺼둠

2
WIRES-X 소프트웨어 실행

바탕화면 "WIRES-X" 아이콘 (ADMS-18과는 별개 프로그램)

3
무전기를 원하는 모드로 켜기

위 표 참고 — PDN 또는 Portable HRI

4
소프트웨어가 무전기를 인식하는지 확인

화면 상단이 "P-HRI FTM-510D" 등으로 바뀌고, 우하단에 "ONLINE(IPv4)" 표시

3. 무전기 본체에서 검색·접속

무전기가 PDN/HRI 모드로 정상 부팅되고 PC와 통신 중이면(화면에 "WIRES-X PDN" 표시가 점멸하지 않는 정상 대기 상태), 본체 버튼으로 직접 룸/노드를 검색·접속할 수 있습니다.

3-1. 접속 시작

1
[D X] 키를 짧게 누름

화면 좌측 상단 "X" 아이콘이 점멸하며 접속을 시작. PC와 정상 통신되면 점멸 → 점등으로 바뀌고 자국 노드 ID·도시명이 표시됨

3-2. 룸/노드 목록에서 선택 접속

1
화면 하단 "SEARCH & DIRECT" 표시 상태에서 FUNC 노브로 선택 → FUNC 확정
2
카테고리 목록에서 FUNC 돌려 "ALL" 선택 → FUNC 확정

접속 가능한 룸·노드 전체 목록 표시 (룸 다음 노드 순)

3
FUNC 돌려 원하는 룸/노드 선택 → FUNC 확정 (또는 선택 후 바로 PTT)

접속 성공 시 화면에 "Connected" 및 접속 대상 이름 표시

3-3. DTMF ID로 직접 접속 (노드 번호를 알 때 — 가장 빠름)

1
마이크 [#] 키를 길게 누름

DTMF ID 입력 화면 표시

2
마이크 숫자 키패드로 5자리 노드번호 입력
3
[#] 키를 다시 눌러 확정

접속 성공 시 "Connected" 표시

3-4. 교신 및 종료

1
PTT로 교신 — 누르면 송신, 놓으면 수신
2
접속 해제 — 마이크 [*] 키 길게 누름, 또는 PC 소프트웨어 접속 메뉴에서 "절단"
4. 접속·조작이 안 될 때 확인할 것
증상원인/설명
[D X] 눌러도 X 아이콘이 안 뜨거나 바로 사라짐PC·무전기 간 통신이 안 되는 상태. "WIRES-X PDN" 표시가 점멸 중이면 케이블/드라이버/COM포트 재확인 필요
이미 룸/노드에 접속된 상태에서 FUNC·DIAL 등 본체 버튼이 전혀 안 먹음정상 동작. 노드가 PC 소프트웨어에 의해 제어되는 상태에서는 본체 로컬 버튼이 잠기고, 마이크 숫자 키패드([#]/[*])만 계속 살아있음
PTT 눌러도 "TX Prohibit" 삐빅음ON-AIR LOCK 상태(다른 국 송신 중이거나 접속 직후 안정화 대기) — 몇 초 기다린 뒤 재시도, 또는 룸 재접속
접속 중 반복적으로 자동 끊김 (Digital transceiver error reset)일부 룸은 일정 시간 무통신 시 자동 이탈시키는 정책 운영 — 정상 동작. PTT 한 번 ON/OFF로 재접속됨
ADMS-18(메모리 편집)에서 CLONE 통신이 계속 실패WIRES-X 노드 운용과는 별개 문제. 무전기 사양(일본 내수/해외 수출)과 ADMS-18 언어판이 일치해야 함
