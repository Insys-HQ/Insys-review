🔢
WIRES-X 회원 등록 단계
1
WIRES-X 사이트 접속

야에수 WIRES-X 공식 사이트에 접속합니다.

https://www.yaesu.com/jp/en/wires-x/index.php

좌측 메뉴에서 "WIRES-X ID registration → [Member registration]" 클릭

2
이메일 인증

이메일 주소 입력 후 "Send" 클릭 → 등록 URL이 메일로 발송됩니다.

⚠️ 주의모바일(nate.com, daum 앱 등) 이메일은 사용 불가. PC 이메일 권장.
3
이용약관 동의

수신된 메일의 URL 클릭 → WIRES-X Server End-User License Agreement 화면

"I agree to WIRES-X server license agreement" 체크 → "Agree and proceed" 클릭

4
회원 정보 입력

아래 항목을 입력합니다. HL2TLS 실제 등록 예시:

PDN 노드는 HRI-200 없으므로 Radio ID(5자리) 입력란에 Radio ID 입력.
5
최종 확인 및 제출

Confirmation 화면에서 입력 내용 검토 후 "Send" 클릭

6
등록 완료 메일 수신

등록 완료 후 야에수에서 아래 ID가 포함된 메일이 발송됩니다.

Room ID (69043): 이 노드가 개설한 룸에 접속할 때 사용하는 번호
Radio ID (FDfrt): 기기 고유 ID (변경 불가)
7
WIRES-X PC 소프트웨어 설치

Node owner's page에서 최신 소프트웨어 다운로드 후 설치

  • SetupMenu64.exe 실행 (64비트 Windows)
  • ① HRI-200 Device Driver Setup 먼저 설치
  • ② WIRES-X Software Setup (Ver.2.010) 설치
  • 설치 시 "Enable WIRES-X Auto Start" 체크 권장
  • 실행 시 반드시 관리자 권한으로 실행
