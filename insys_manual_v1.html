2. 핵심 원칙 4가지

Foundation

① 사업유형 → 고객사 → 카테고리

3단계 고정 계층. 새 고객사가 들어와도 항상 같은 자리에 같은 구조로 배치합니다.

예: 4_아웃소싱사업 / B_경비·미화 / 위너콤 / 04_월별청구 / 2026 / 05월

② 파일명만 봐도 내용 파악

경로에 있는 정보(고객사·연월)는 파일명에서 제외. 유형과 버전만 남깁니다.

예: 청구서_경비미화_v1.0.pdf (위너콤 폴더 안에 있으므로 회사명 생략)

③ 공통서식은 0_공통서식에만

모든 양식 마스터는 0_공통서식에만 둡니다. 각 고객사 폴더에는 작성본만.

예: 양식_근로계약서_경비_v1.0.docx → 항상 0_공통서식/01_근로계약서

④ 각 고객사 폴더에 _Index.md

담당자·계약기간·인력·연락처를 30초 안에 파악할 수 있는 요약 파일 필수.

예: 인수인계 시 신규 담당자가 _Index.md만 읽으면 즉시 업무 파악

📌 5-4. 금지 사항

금지이유대안
"최종"·"진짜최종"·"v2최종"다음 수정 시 또 "최종" 추가됨버전을 올려라 (v2.0)
"복사본"·"- 복사본"중복 파일 양산삭제 (필요 시 _Archive)
파일명에 회사명 두 번"위너콤 경비,미화 청구서_In-sys Co. Ltd"회사명 1번만
날짜 폴더 + 파일명에 날짜중복 정보경로에 있으면 파일명에서 제외
Thumbs.db / desktop.ini / ~$파일시스템·임시 파일즉시 삭제

⚠ 핵심 원칙
최신 버전 1개만 활성 폴더에 둡니다.
구버전은 _Archive 폴더로 즉시 이동합니다.
같은 폴더에 v1.0·v1.1·v2.0이 동시에 있으면 안 됩니다.

9. 자주 묻는 질문 (FAQ)

Common Questions
기존 파일은 다 옮겨야 하나요?
아닙니다. 신규 파일부터 새 구조를 적용합니다. 기존 자료는 _BACKUP에 그대로 있고, 필요할 때 새 구조로 복사하면 됩니다.
같은 고객사에 경비와 미화를 동시에 운영합니다. 어디에 둬야 하나요?
B_경비·미화 폴더의 같은 고객사 폴더 안에서 경비/미화를 구분합니다. 예: 위너콤 / 03_급여_출근부 / 경비 + 미화
파일 버전을 어떻게 올리나요?
오타·부분 수정은 v1.1·v1.2, 구조나 내용이 크게 바뀌면 v2.0으로 올립니다. 구버전은 _Archive 폴더로 즉시 이동합니다. 절대 "최종"·"최종2"·"진짜최종" 같은 표기 금지.
고객사가 새로 들어왔습니다. 어떻게 만드나요?
사업유형 확인 후 (A/B/C 중 하나) 해당 폴더에 고객사명 폴더 생성, 표준 6개 하위 폴더(01~05 + _Index.md) 만들면 끝. 양식은 0_공통서식에서 복사해서 채워 넣습니다.
청구서 PDF는 어디에 저장하나요?
4_아웃소싱사업 / [사업유형] / [고객사] / 04_월별청구_정산 / [연도] / [월] / 청구서_도급비_v1.0.pdf 형태로 저장합니다.
_Index.md는 어떻게 작성하나요?
아래 11번 섹션의 양식 그대로 복사해서 채우면 됩니다. 담당자·계약기간·인력·연락처·특이사항만 들어가면 충분합니다.
Thumbs.db나 ~$파일이 자꾸 생깁니다.
Windows에서 자동 생성되는 시스템·임시 파일입니다. 발견 즉시 삭제하면 됩니다. 업무에 영향 없습니다.
백업 폴더(_BACKUP_2026-06_OLD)는 언제 삭제되나요?
6개월 후 사용 빈도 검토, 1년 후 NAS 또는 외부 저장소로 이관합니다. 절대 무단 삭제하지 않습니다.
