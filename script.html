제안 배경
왜 지금, 왜 인시스인가?
1분 30초
위너콤에서도 이미 일부 기종에 비전 검사기 도입을 진행 중인 것으로 알고 있습니다. 딥러닝 검사는 방향은 분명하지만, 화면에 정리해 드린 것처럼 학습과 검출력 안정화 과정이 성패를 가릅니다. 여기서 인시스의 강점을 말씀드리면, 저희는 양산 검사기를 개발·납품한 실적을 보유한 핵심 엔지니어사와 전략적 협약을 맺고 있습니다. 그래서 검증된 노하우로 시행착오를 줄여 더 빠른 결과를 만들어 드릴 수 있고, 최종적으로는 위너콤 공정에 특화된 솔루션으로 최적화합니다.

✓ 강조 포인트 (PPT 4카드 순서대로)

  • 검출력 안정화가 관건 → 검증된 파트너십 → 더 빠른 결과 → 위너콤 최적화
  • 위너콤이 이미 도입 중임을 인지하고 있음을 보여 신뢰 형성
  • 협약사 = 양산 실적 보유, "더 빠른 결과"를 자신 있게 제시

💬 예상 질문

  • 이미 다른 업체와 진행 중인데?→ 경쟁이 아닌 보완·비교 관점. 검증기로 부담 없이 검출력을 직접 비교해 보시라고 제안
  • 그 엔지니어사가 어디인가?→ 협약사 정보는 상세 협의 단계에서 공유. 양산 납품 실적이 있다는 점만 강조

스마트 카메라 vs 딥러닝 비전 성능 비교
최적 조명 선택이 정확도를 결정
1분 30초
기존 스마트 카메라는 룰 기반이라 명확한 불량만 잡을 수 있고 조명 변화에 취약합니다. 반면 딥러닝 비전은 패턴을 학습하기 때문에 모호한 불량까지 검출하고, 운영할수록 정확도가 올라갑니다. 특히 조명이 중요합니다. 돔 조명은 형상과 엣지 검출에, 동축·Low Angle 조명은 표면 스크래치와 미세 흠집 검출에 유리합니다. 검사 목적에 맞춰 조명을 조합하는 것이 검출력의 핵심입니다.

✓ 강조 포인트

  • 조명 전문성을 보여 기술 신뢰 확보

💬 예상 질문

  • 검출율이 몇 %인가?→ 샘플 확보 후 검증에서 실제 수치 제시. 협약사의 양산 실적 기준으로 목표치는 제시 가능하나, 위너콤 제품 기준 수치는 검증 후 확정

시스템 개요 및 검사 프로세스
지그 안착부터 양불 분리 배출까지
1분 30초
전체 검사 흐름입니다. 지그 안착 → 바코드 스캔 → 자동 인식 → 이송·촬영 → 딥러닝 판정 → MES 전송 → 자동 배출 순서로 진행됩니다. 여기서 한 가지 협조를 부탁드립니다. 검사 지그에 PCB를 올릴 때 바코드가 항상 위를 향하고 같은 위치에 오도록 지그를 설계해야 인식률이 안정적입니다. 그리고 검사원분들이 현장에서 판별해 온 불량 데이터를 학습에 활용하면 초기 정확도를 크게 높일 수 있습니다.

✓ 강조 포인트

  • NG 자동배출은 '추후 옵션'임을 언급 — 검증기엔 없음
  • 현장 데이터 제공을 자연스럽게 요청

💬 예상 질문

  • 바코드 위치를 못 맞추면?→ 지그 설계로 해결 가능. 현장 실사에서 함께 검토

독립적인 검사기 예시

실제 구성 예시 이미지입니다. 상부에 카메라와 돔 조명, 좌우에 45도 방향 조명이 배치되고, 대상품은 컨베어를 따라 검사 위치를 지나갑니다. 우측 모니터로 실시간 판정 결과를 확인합니다. 이건 완성형 예시이고, 실제 사양은 위너콤 라인에 맞춰 조정됩니다.

✓ 강조 포인트

시스템 구성 & MES 데이터 연계
딥러닝 검사 확인 후
1분
검사기는 흐름 라인 연계, 검사 지그, 카메라·조명, 딥러닝 판정부, 양불 분리, 바코드 스캐너로 구성됩니다. 검사 결과는 MES와 연계되어 수기 입력 없이 자동 전송되고, 제품별 이력 추적과 품질 대시보드까지 이어집니다. 다만 이 연계는 딥러닝 검출력이 검증된 뒤 단계에서 적용하는 것을 권장드립니다.

💬 예상 질문

  • 우리 MES랑 연동 되나?→ 대부분 가능. 연동 방식·범위는 실사 때 IT 담당자와 확인 필요

핵심 장점 & 도입 효과
품질·운영·경쟁력
1분
도입 효과를 세 가지로 정리했습니다. 품질 면에서는 불량 검출율이 지속 향상되고 불량이 데이터로 관리됩니다. 운영 면에서는 검사 공정이 무인화되어 인력을 생산에 재배치할 수 있습니다. 경쟁력 면에서는 납품처 신뢰도가 올라가고 클레임 대응 근거 데이터를 확보하게 됩니다.

✓ 강조 포인트

  • '인력 감축'이 아니라 '재배치'로 표현 — 거부감 완화

확장성 — 추가 라인 도입 시 이점
데이터 자산이 확장의 토대
50초
확장 관점입니다. 화면의 흐름처럼 1호기 도입 → 효과 검증 → 학습 데이터 자산화 → 추가 라인 도입 → 전 라인 적용으로 이어집니다. 핵심은 첫 검사기에서 쌓인 양품·불량 이미지가 자산으로 남는다는 점입니다. 그래서 추가 라인에 확대할 때는 처음부터 다시 학습하는 게 아니라 기존 데이터를 재활용해서, 개발 기간을 단축하고 비용을 절감하며 도입 즉시 높은 검출율을 확보합니다. 한 대로 끝나는 투자가 아니라 늘릴수록 유리해지는 구조입니다.

✓ 강조 포인트 (PPT 3효과 카드)

  • 개발 기간 단축 · 비용 효율 향상 · 품질 정확도 가속
  • "데이터 자산화"가 확장의 토대라는 메시지 각인
10
진행 절차 — 단계별 도입 전략
핵심 슬라이드
2분
오늘 가장 중요한 부분입니다. 저희는 처음부터 완전 자동화 설비를 제안드리지 않습니다. 1단계로 검증기를 먼저 제작합니다. 작업자가 올려놓고 딥러닝이 양불만 판정하는 단순한 형태로, 제작비와 기간을 최소화합니다. 제작 기간은 대략 3~4주면 됩니다. 이걸로 딥러닝이 검사원 이상으로 잡아내는지 먼저 검증합니다. 검증이 확인되면 2단계로 양산형을 제작합니다. 이때 자동 투입·배출, 바코드 자동 스캔, NG 자동 분리 같은 기능을 위너콤 라인에 맞춰 구성합니다. 즉, 결과를 먼저 확인하고 확장 여부를 결정하는 안전한 순서입니다.

✓ 강조 포인트 (PPT STEP1/STEP2 + 6단계)

  • 검증기(수동)로 부담 최소화 → 검증 → 양산형 기능 확장
  • 하단 6단계: 샘플→검토리포트→사양확정→제작→시범적용→검출력검증
  • "결과 먼저 확인 후 확장" = 안전한 접근

💬 예상 질문

  • 검증에 얼마나 걸리나?→ 제작 3~4주 + 시범 적용 기간. 샘플 확보 상황에 따라 조정
  • 검증 실패하면?→ 다음 장 임대 방식으로 리스크 최소. 자연스럽게 사업모델로 연결
11
사업 모델 — 부담 없는 임대 방식
인시스 투자·제작 → 위너콤 임대
1분 30초
도입 방식은 임대입니다. 인시스가 검사기를 투자·제작하고 위너콤은 월 임대료로 사용하십니다. 그래서 첫째, 초기 설비 투자 부담이 없고, 둘째, 검증에 실패하더라도 고객사 손실 리스크가 최소이며, 셋째, 정기 점검과 모델 재학습, A/S가 임대료에 포함됩니다. 임대료는 기능에 따라 달라집니다. 검증기는 기본, 양산 표준형은 자동 투입·배출과 바코드 스캔, 고급형은 NG 자동 분리와 MES 연동까지 — 필요한 기능만 선택하시면 그에 맞춰 임대료가 정해집니다. 부담 없이 검증부터 시작해 보시길 권합니다.

✓ 강조 포인트 (PPT 3특징 + 임대료표)

  • 초기 투자 없음 · 리스크 최소 · 유지관리 포함
  • 검증기(기본) → 표준형(중간) → 고급형(높음) 3단계 임대료
  • "부담 없이 검증부터"가 이 슬라이드의 결론

💬 예상 질문

  • 검증기 월 임대료는 얼마인가?→ 검증형 기준 개념 금액 제시 가능, 정확한 금액은 실사 후 상세 제안서에서 확정
  • 임대 기간과 중도 해지는?→ 통상 24~36개월 협의. 조건은 임대 계약 시 세부 협의
12
예상 문제점 및 협의 사항
현장 적용 전 사전 검토
1분 30초
솔직하게 미리 짚어야 할 부분도 말씀드립니다. 케이블이 달린 PCB의 형태 균일화와 바코드 위치 표준화, 흐름 라인에서 지그 회수 방법, 여러 개를 동시에 올릴 수 있는지, 그리고 기존 육안검사 데이터 제공 여부입니다. 이런 부분들을 오늘과 현장 실사에서 함께 확인하면, 시행착오 없이 최적의 검사기를 만들 수 있습니다.

✓ 강조 포인트

  • 문제를 미리 꺼내는 것이 오히려 신뢰를 준다 — 솔직하게
  • 여기서 고객 답변을 최대한 받아 적기 (자료 확보 핵심 구간)
13
다음 단계
클로징
1분
