WIRES-X 노드 시작 절차
STEP 1
PC 소프트웨어 먼저 실행
  • PC에서 WIRES-X 소프트웨어 실행
  • 자동으로 Yaesu 서버에 로그인 (ID: rnfql4989)
  • 화면 상단 노드 상태 녹색(Online) 확인
  • HRI-200 COM포트 인식 확인
⚠️ 소프트웨어 먼저 켜야 함. 리그 먼저 켜면 PDN 깜박임 발생
STEP 2
리그 WIRES-X 모드 진입
  • FTM-510D 전원 ON
  • ② DX 버튼 장누름 (약 1초)
  • 화면에 "WIRES-X" 표시 확인
  • 소프트웨어 연동되면 노드 목록 표시됨
PDN 깜박임 → 소프트웨어 미실행 또는 인터넷 오류
STEP 3
노드/룸 검색 및 연결
  • 리그 화면에서 FUNC 노브 돌려 검색
  • 또는 소프트웨어에서 룸/노드 검색 후 클릭
  • Room 07517 선택 → 연결
  • 연결 완료: 화면에 룸명·참가국 수 표시
STEP 4
교신 준비 완료
  • 로컬 주파수로 핸디 또는 리그 설정
  • PTT 누르고 콜사인 + CQ 송출
  • 상대국 응답 시 일반 교신과 동일하게 진행
  • 종료 후 DX 장누름으로 WIRES-X 해제
