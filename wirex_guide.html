①
디지털(C4FM) 모드 설정
💡
C4FM 디지털이란?Yaesu 독자 디지털 방식. 콜사인·GPS 위치 자동 표시, 음질 우수. 상대방도 C4FM 지원 기종 필요.
STEP 1
C4FM 디지털 모드 진입
  • ⑥ 전원 버튼 + ② DX 버튼 동시 누름으로 전원 ON
  • 화면에 DN (C4FM 디지털) 표시 확인
  • 이후 운용 중 모드 변경: DX 단누름 반복
  • 순서: AMS → DN → FM → AMS (순환)
전원+DX 동시 누름 = C4FM 디지털 전용 부팅. AMS = 자동 판별(C4FM·FM 혼용 환경 권장)
STEP 2
주파수 설정
  • 메인밴드에 교신 주파수 입력
  • 상대국 또는 디지털 레피터 주파수 확인
  • WIRES-X 노드 사용 시 노드 주파수 입력
  • C4FM 레피터: 오프셋 방향 확인 (±600kHz 등)
STEP 3
DG-ID 설정 (필요 시)
  • ① GM 버튼 장누름 → DG-ID 설정 화면
  • FUNC 노브로 DG-ID TX / RX 번호 선택
  • 특정 그룹 전용: DG-ID 00 이외 번호 지정
  • 일반 교신: DG-ID 00 (모든 국 수신)
DG-ID 불일치 시 수신은 되지만 스켈치가 열리지 않음
STEP 4
GM(그룹모니터) 활용
  • ① GM 버튼 단누름 → GM 기능 ON
  • 교신 가능 범위 내 C4FM 국 자동 스캔·표시
  • 화면에 감지된 국 콜사인·거리 표시
  • 상대국도 GM ON 상태여야 상호 표시

①
아날로그(FM) 모드 설정
💡
FM 아날로그란?일반 FM 핸디트랜시버와 교신하는 전통 방식. 어떤 브랜드 FM 무전기와도 교신 가능.
STEP 1
FM 모드 전환
  • ② DX 버튼 단누름 2회 → FM 표시
  • 순서: AMS → DN → FM → AMS
  • 화면에 FM 표시 확인
  • 아날로그 전용 교신 시 FM 고정 권장
AMS에서도 아날로그 신호 수신 가능하나, FM 고정이 더 안정적
STEP 2
주파수 · 스켈치 설정
  • 상대국 주파수로 VFO 설정
  • 스켈치: 캐리어 스켈치 (CTCSS/DCS OFF)
  • 특정 그룹 전용: CTCSS 톤 코드 지정
  • 레피터 사용 시 오프셋 방향·CTCSS 확인
CTCSS 설정 시 동일 톤 없는 국은 수신 안 됨 — 개방 교신 시 OFF
STEP 3
출력 설정
  • FUNC 노브 메뉴 → TX 출력 선택
  • High(50W) / Mid(20W) / Low(5W)
  • 근거리: Low, 원거리·레피터: High
  • 차량 설치 시 안테나 SWR 확인 필수
STEP 4
레피터(중계기) 경유 교신
  • 레피터 출력 주파수로 수신 주파수 설정
  • 오프셋: -600kHz (144MHz대) / -5MHz (430MHz대)
  • CTCSS 톤: 해당 레피터 지정 톤 코드 입력
  • PTT 누르면 오프셋 주파수로 자동 송신
레피터 정보: 한국아마추어무선연맹(KARL) 레피터 목록 참조

WIRES-X 노드(중계기) 모드 설정
⚠️
사전 조건PC + HRI-200 + WIRES-X 소프트웨어 필수. 소프트웨어 먼저 실행 → 이후 리그 WIRES-X 모드 진입 순서 반드시 준수.
STEP 1
PC 소프트웨어 실행
  • PC에서 WIRES-X 소프트웨어 실행
  • Yaesu 서버 자동 로그인 확인 (ID: rnfql4989)
  • 소프트웨어 상태: Online(녹색) 확인
  • HRI-200 COM포트 정상 인식 확인
PDN 깜박임 = 소프트웨어 미실행 또는 인터넷 단절
STEP 2
리그 WIRES-X 모드 진입
  • FTM-510D ② DX 버튼 장누름 (약 1초)
  • 화면에 WIRES-X 표시 확인
  • 노드 목록 자동 표시됨
  • 종료: DX 버튼 재장누름 → 일반 모드 복귀
STEP 3
운용 모드 선택 (핵심)
  • 아날로그 핸디 수용: FM 모드 고정
  • C4FM 핸디 수용: AMS 또는 DN 모드
  • 혼용(아날+디지털): AMS 모드 권장
  • 모드 전환: DX 단누름으로 FM ↔ AMS ↔ DN
AMS = 신호 방식 자동 판별. 혼용 환경에서 가장 유연
STEP 4
룸/노드 연결
  • 소프트웨어에서 Room 07517 검색·연결
  • 또는 FUNC 노브로 리그 화면에서 선택
  • 연결 완료: 화면에 룸명·참가국 수 표시
  • 이후 로컬 핸디가 PTT 누르면 WIRES-X 망 자동 중계
