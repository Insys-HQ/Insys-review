PDN 방식에서 HRI-200 방식으로 전환하는 전체 절차

문서버전 v1.0 작성일 2026-08-16 대상 6K2JPO / FTM-300DR·DE
전제 조건
  • 현재 PDN(Portable Digital Node) 모드로 설정되어 있음 → HRI-200 방식으로 전환
  • SCU-58 케이블 없음 / HRI-200 유닛 보유
  • 리그: FTM-300DR·DE (해외수출사양)
  • Node ID 97517 등록 완료, HRI-200 시리얼·Radio ID 등록 완료
  • 공유기 포트포워딩 불필요 — Room 접속만 하므로 인바운드 연결이 필요 없음
1

기존 PDN 설정 정리

  1. WIRES-X 소프트웨어를 완전히 종료 (작업표시줄 우측 시스템 트레이 아이콘까지 확인)
  2. FTM-300 전원 OFF
주의 — WIRES-X가 시스템 트레이에 남아 있으면 COM 포트를 점유하여 이후 설치가 진행되지 않습니다.
2

HRI-200 드라이버 설치

  1. WIRES-X 로그인 페이지 접속 → 6K2JPO 계정으로 로그인
  2. Node Owners Page 진입 → WIRES-X Software (zip) 다운로드
  3. zip 압축 해제 (USB는 아직 연결하지 않음)
  4. Install.exe 실행 → [HRI-200 Device Driver Setup] 클릭
  5. "USB를 연결하세요" 안내가 나오면 그때 HRI-200을 PC에 USB 연결
순서 엄수 — 반드시 드라이버를 먼저 설치한 후 소프트웨어를 설치합니다. 순서가 바뀌면 COM 포트를 인식하지 못합니다.
3

COM 포트 인식 확인

  1. 키보드 Windows + X → 장치 관리자 실행
  2. 포트(COM & LPT) 항목 펼치기 → HRI-200 Communication device A (COM○) 확인 후 번호 메모
  3. 사운드, 비디오 및 게임 컨트롤러 → HRI-200 A(CH1) USB Audio codec 확인
정상 — 위 두 항목이 모두 보이면 드라이버 설치가 완료된 것입니다. 느낌표(⚠) 표시가 있으면 드라이버를 재설치합니다.
4

WIRES-X 소프트웨어 설치

  1. 동일한 Install.exe에서 [WIRES-X Software Setup] 클릭
  2. 라이선스 동의 → 설치 진행
  3. 설치 완료 후 PC 재부팅
5

6

FTM-300을 HRI-200 모드로 부팅

  1. 리그 전원 OFF 상태에서 시작
  2. 지정된 키 조합을 누른 채로 전원 ON
  3. 화면이 일반 VFO 화면이 아닌 HRI-200 연동 모드로 부팅되는지 확인
사전 확인 필요 — FTM-300DR의 HRI-200 모드 진입 키 조합은 FTM-510D([GM]+[DG3])와 다릅니다. FTM-300DR 취급설명서에서 반드시 확인 후 진행하십시오.
7

WIRES ID Activation (노드 인증)

  1. 리그를 먼저 켠 상태에서 WIRES-X 소프트웨어 실행
  2. COM 포트 선택 → 3단계에서 메모한 번호 지정
  3. WIRES ID Activation 창에서 각 항목 입력
항목입력값
Serial/Radio ID자동 표시됨 (리그가 켜져 있어야 함 — 직접 입력 불가)
Node → DTMF ID6K2JPO의 DTMF Node 코드
Room → DTMF ID비워둠 (자체 Room을 개설하지 않으므로)

입력 후 [ID Entry] 클릭 → CallSign / City / State / Country가 자동으로 채워지면 인증 성공 → [OK]

DTMF ID ≠ Node ID — Node ID(97517)와 DTMF Node 코드는 서로 다른 값입니다. Node Owners Page 계정 정보에서 DTMF 코드를 확인하여 입력하십시오.
Retry activation 금지 — File 메뉴의 Retry activation은 서버 등록 정보를 삭제하는 명령입니다. 인증 완료 후에는 절대 실행하지 마십시오.

아날로그 선택 이유 — 6K2JPO는 DS0ARC(신월동)와 핸디 직접교신이 불가능한 거리에 위치하므로, 아날로그로 설정하면 해당 권역의 아날로그 무전기 사용자를 별도로 커버하게 되어 RC-Net 전체 커버리지가 확대됩니다.
주파수 사전 확인 — 145.640 MHz가 6K2JPO 지역에서 다른 용도로 사용 중이지 않은지, 밴드플랜상 문제가 없는지 확인 후 확정하십시오.

DS0ARC Room(48182) 접속

접속 방법은 두 가지입니다.

방법조작
소프트웨어에서하단 Room 리스트에서 DS0ARC-ROOM2 (48182) 검색 후 접속
무전기에서DTMF 키패드로 #48182 입력
[Setup] 버튼 사용 금지 — Round QSO room settings 화면의 [Setup] → Room Active → Room Activation은 Room을 개설하는 호스트국(DS0ARC)만 수행하는 절차입니다. 6K2JPO는 접속만 하므로 이 과정을 진행하지 않습니다.
11

정상 동작 확인

확인 항목정상 상태
우측 하단 상태표시ONLINE
상단 표시등NET (녹색) 점등 + DS0ARC-ROOM2 표시
DS0ARC 호스트 화면member 카운트 증가
아날로그 핸디 테스트145.640 MHz / TSQ 88.5 Hz 설정 후 PTT 시 ON-AIR 표시등 점등
참고 — "Digital transceiver error reset code=1060100" 메시지는 무통신 상태에서 Room이 자동 이탈될 때 발생하는 정상 현상이며, PTT ON/OFF로 재접속됩니다. 고장이 아닙니다.
