사전 확인 완료 DS0ARC ROOM(48182)은 정상 가동 중이며, RC-Net 봉사원 모바일 무선국(HL1LFC·6K2JPO·HL1LGZ 등)은 전부 SCU-58 케이블 키트로 통일되어 있어 이 가이드 하나로 공통 적용됩니다.

0운용모드 2가지

DS0ARC ROOM에 접속하기 전, 먼저 두 모드 중 하나를 선택해서 무전기를 켭니다.

1모드 진입 및 노드 운용 시작

① PDN 모드로 켜기 (디지털 전용)

  1. SCU-56(USB)만 무전기 DATA단자와 PC에 연결 (오디오케이블 미사용)
  2. D X키를 누른 채 전원 스위치 길게 눌러 ON
  3. 화면 하단에 "WIRES-X PDN" 표시 확인
  4. PC에서 WIRES-X 소프트웨어 실행 (인증 완료 상태면 자동 연동)

② Access Point / Direct 선택

노드 운용을 시작하기 전, 이 화면에서만 전환할 수 있습니다.

리그Access/Direct 전환 키
FTM-510D위/아래 화살표 키 짧게 누름
FTM-300DA/B키 짧게 누름
  • 화면에 "(주파수)" 표시 = Access Point (전파도 동시 송신)
  • 화면에 "DIRECT" 표시 = Direct (전파 송신 없이 인터넷으로만)
자택에서 개인 운용 시에는 Direct를 권장합니다 — 전파를 쓰지 않고 PC+무전기만으로 인터넷 교신하는 방식이라 근처 C4FM 수신국을 신경 쓸 필요가 없습니다.

③ 노드 운용 시작

리그노드운용 시작 키
FTM-510D / FTM-300DD X키 짧게 누름 (또는 마이크 P3키)

화면 "X" 아이콘이 점멸 → 점등으로 바뀌면 노드 운용 시작 완료. 자국 노드ID와 도시명이 표시됩니다.

Access/Direct를 바꾸고 싶다면 D X키를 길게 눌러 다시 ② 화면(주파수 설정화면)으로 돌아간 뒤 전환 → 다시 ③ 절차로 노드운용을 재시작하세요.

4DS0ARC ROOM 접속 (또는 다른 ROOM)

방법 A — DTMF 번호 직접 입력 (가장 빠름, 추천)

  1. 마이크의 #키를 길게 누름 → DTMF ID 입력화면
  2. 접속하려는 룸의 5자리 DTMF ID 입력 — DS0ARC ROOM = 48182
  3. 마이크 #키 짧게 누름 → 접속 개시
  4. 화면에 "Connected" + 접속처 이름 표시되면 성공

다른 룸도 같은 방식으로, 해당 룸의 DTMF ID만 바꿔 입력하면 됩니다.

방법 B — 목록에서 검색해서 접속

  1. [SEARCH & DIRECT] 선택
  2. [ALL] 선택 → 현재 활성화된 모든 노드·룸 목록 표시 (룸이 먼저, 노드가 다음 순서로 표시되며 룸은 우측에 현재 접속 국수 표시)
  3. 원하는 룸 선택 → 접속 시작
  4. 이름 일부만 입력해 전방일치 검색도 가능 (예: "DS0" 입력 시 DS0ARC 관련 항목만 표시)

방법 C — 마지막 접속처로 재접속

이전 접속 이력이 있으면 화면 하단에 점멸 표시됩니다. PTT를 누르거나 해당 항목을 선택하면 바로 재접속됩니다.

방법 D — 카테고리(즐겨찾기) 등록

한 번 접속한 룸·노드를 우클릭 → [카테고리 등록] → C1~C5 중 선택해 저장. 다음부터는 SEARCH & DIRECT → 등록한 카테고리에서 바로 선택할 수 있습니다.

5교신 (PTT)

  • PC에 연결된 무전기의 PTT 스위치를 눌러 말합니다.
  • Direct 운용: 인터넷으로만 중계, TX LED는 켜지지만 전파는 송신되지 않습니다(PO미터 안 움직임) — 정상입니다.
  • Access Point 운용: 인터넷 중계와 동시에 C4FM 전파도 송신, 근처 C4FM 리그가 직접 청취 가능합니다.
  • PTT를 떼면 상대방 음성이 스피커로 재생됩니다.

6접속 종료

  • 마이크의 *키를 길게 눌러 접속 해제
  • 또는 WIRES-X 소프트웨어 [접속] 메뉴 → [절단]

7FM(아날로그) 모드로 DS0ARC와 교신하기

DS0ARC ROOM 내에서 아날로그 FM국(HRI-200 노드 등)과 직접 교신하려면 PDN 모드가 아니라 포터블 HRI 모드로 다시 켜야 합니다.

  1. 무전기 전원을 완전히 끕니다.
  2. 오디오케이블을 추가로 연결합니다 — SCU-58 구성품 중 오디오케이블을 무전기 스피커단자·마이크단자에 연결 (기존 USB 연결은 그대로 유지)
  3. D X+GM키를 동시에 누른 채 전원 스위치 길게 눌러 ON
  4. 화면에 "WIRES-X"(PDN이 아닌) 표시 확인 — 이게 뜨면 HRI 모드 진입 성공
  5. 이후 절차(Access/Direct 선택 → 노드운용 시작 → ROOM 접속 → PTT 교신)는 위 1~6번과 동일한 방식으로 진행합니다.
DS0ARC ROOM 정상 가동 확인됨 운용형태 설정에 문제가 없어 PDN(디지털)·HRI(아날로그FM) 접속 모두 정상적으로 가능합니다.

8요약 흐름도

전원 OFF │ ├─ D X만 누르고 ON → PDN(디지털전용) 모드 │ └─ Access/Direct 선택 → 노드운용 시작 → DTMF 48182 입력 → PTT 교신 │ └─ D X + GM 동시 누르고 ON (오디오케이블 연결 필수) → HRI(디지털+FM) 모드 └─ Access/Direct 선택 → 노드운용 시작 → DTMF 48182 입력 → PTT 교신
