FTM-300DR WIRES-X 노드 설정 가이드 (6K2JPO 전용)

6K2JPO(이재영) 국장 개인국 — 프로그램 설치 → PC 연결 → 무전기 설정 → 룸/노드 접속
v1.1 서울 재난대응봉사회 기술팀장
개요

6K2JPO 국장님의 무전기는 FTM-300DR/DE(해외 수출 사양)입니다. 야에스 국제 사이트에서 제공하는 수출용 소프트웨어(ADMS-12, WIRES-X 케이블 드라이버)를 사용해야 합니다. 이 문서는 PC에 설치할 프로그램부터 순서대로 안내합니다.

1. 설치해야 할 프로그램 (순서대로)

야에스 국제 사이트 제품 다운로드 페이지에서 아래 항목들을 미리 받아두세요.

순서프로그램용도
1PL23XX_Prolific_DriverInstaller (버전 402)WIRES-X 케이블(SCU-56/SCU-20)의 USB-Serial 통신을 위한 필수 드라이버
2WIRES-X 연결 케이블 키트 드라이버 설치 설명서(2205A)위 드라이버 설치 시 참고용 공식 설명서
3WIRES-X 소프트웨어 (WIRES-X 홈페이지 로그인 후 다운로드)PC에서 노드를 운용하는 핵심 프로그램
4FTM-300DR/FTM-300DE 프로그래밍 소프트웨어 ADMS-12메모리 채널 편집용 (선택 — 메모리 작업 시에만 필요)
🚨
반드시 케이블을 PC에 꽂기 전에 1번(Prolific 드라이버)부터 설치하세요. 순서를 바꾸면 Windows가 엉뚱한 드라이버를 잡을 수 있습니다.
2. Prolific 드라이버 설치
1
PL23XX_Prolific_DriverInstaller (버전 402) 실행

케이블은 아직 PC에 꽂지 않은 상태

2
설치 마법사 안내대로 Next → Install → Finish
3
설치 완료 후 WIRES-X 케이블(SCU-56/SCU-20)을 PC USB 포트에 연결
3. 드라이버 설치 확인 (Windows 장치관리자)

케이블을 꽂은 뒤, 아래 단축키로 바로 확인할 수 있습니다.

방법단축키 / 절차
단축키로 바로 열기Win + X 누른 뒤 M 키 (장치관리자 메뉴 밑줄 글자)
또는 실행창으로 열기Win + R → devmgmt.msc 입력 → Enter
1
장치관리자에서 "포트(COM & LPT)" 항목 펼치기
2
"Prolific USB-to-Serial Comm Port (COMxx)" 확인

느낌표(⚠) 없이 정상 표시되면 성공. COM 번호(예: COM5)를 꼭 기억해두세요 — WIRES-X 소프트웨어 설정에 필요

⚠️
느낌표가 뜨거나 "USB-Serial Controller" 같은 미확인 장치로 나오면, 드라이버가 제대로 안 잡힌 것입니다. 케이블을 뽑았다 다시 꽂고, 그래도 안 되면 드라이버 재설치하세요.
4. WIRES-X 소프트웨어 설치 및 실행
1
WIRES-X 웹사이트에 로그인 후 소프트웨어 다운로드·설치

사전에 Radio ID로 노드 등록이 되어 있어야 함

2
바탕화면 WIRES-X 아이콘 실행
3
최초 실행 시 뜨는 설정 화면에서 Serial Number(무전기 시리얼번호)가 자동으로 채워지는지 확인, Node/Room ID 입력

Node/Room ID는 WIRES-X 가입 시 이메일로 받은 번호

4
Windows 보안 경고가 뜨면 "액세스 허용" 클릭
5. 무전기 COM 포트 속도 설정

무전기 DATA 잭의 통신 속도를 WIRES-X 소프트웨어와 맞춰야 합니다.

1
[F(SETUP)] 키를 길게 누름 → SETUP 메뉴 진입
2
DIAL 노브로 [DATA] 카테고리 선택 → DIAL 눌러 확정
3
[1 COM PORT SETTING] 선택 → DIAL 눌러 확정
4
[SPEED] 선택 → DIAL로 원하는 통신속도 선택 (보통 9600bps)

WIRES-X 소프트웨어 COM 포트 설정과 반드시 동일해야 함

6. 무전기 부팅 모드
모드지원 범위켜는 방법화면 표시
일반 모드단독 교신버튼 조합 없이 전원 ON평소 VFO 화면
PDN 모드디지털 전용 인터넷 통신[D X] 키를 누른 채 전원 ON화면 하단 "WIRES-X PDN"
Portable HRI 모드디지털+아날로그 인터넷 통신[D X]+[GM] 키를 동시에 누른 채 전원 ON"YAESU" 로고 + "WIRES-X" 표시
(소프트웨어 정상 통신 시 "WIRES-X NODE"로 바뀜)
💡
한 번 특정 모드로 켠 뒤에는 그 모드를 기억합니다. 이후 버튼 조합 없이 전원만 눌러도 같은 모드로 켜집니다. 일반 모드로 되돌리려면 마지막 사용한 조합을 한 번 더 누른 채 전원을 켭니다.
7. 무전기 본체에서 룸/노드 검색·접속

7-1. 접속 시작

1
[D X] 키를 짧게 누름

"X" 아이콘이 화면에 점멸하며 접속 시작. Access Point 모드면 주파수가, Direct Operation 모드면 "DIRECT"가 표시됨

7-2. 목록에서 선택 접속

1
DIAL 노브로 원하는 카테고리(ALL 등) 선택 → DIAL 확정
2
DIAL 돌려 원하는 룸/노드 선택 → DIAL 확정 (또는 선택 후 바로 PTT)

7-3. DTMF ID로 직접 접속 (노드 번호를 알 때 — 가장 빠름)

1
마이크 [#] 키를 길게 누름
2
마이크 숫자 키패드로 5자리 노드번호 입력
3
[#] 키를 다시 눌러 확정

7-4. WIRES-X DG-ID 설정 (필요 시)

💡
[GM] 키 길게 눌러 설정하는 DG-ID는 일반 DG-ID이고, WIRES-X 노드 접속용 DG-ID는 별도 화면에서 설정합니다. 접속 화면에서 DIAL로 WIRES-X DG-ID를 조정할 수 있습니다 — 특별한 이유 없으면 기본값(00) 유지 권장.

7-5. 교신 및 종료

1
PTT로 교신
2
접속 해제 — 마이크 [*] 키 길게 누름
8. 조작키 요약
기능조작
Access Point ↔ Direct Operation 전환[A/B] 키
일반 DG-ID 설정[GM] 키 길게 누름 → DIAL로 설정
RADIO ID 확인[F(SETUP)] 길게 → DIAL로 "GM" 선택 → [3 RADIO ID CHECK]
접속 중인 룸/노드 절단마이크 [*] 키 길게 누름
소프트웨어 버전 확인[F(SETUP)] 길게 → DIAL로 [DISPLAY] → [5 SOFTWARE VERSION]
9. 자주 겪는 문제
증상원인/조치
[D X] 눌러도 X 아이콘이 안 뜨거나 바로 사라짐PC-무전기 통신 안 됨. COM 포트 속도 불일치 또는 케이블 접촉 불량 확인
룸/노드 접속 후 본체 버튼이 잘 안 먹음정상 동작. 접속 중엔 마이크 [#]/[*] 키만 계속 사용 가능
PTT 눌러도 송신 안 됨다른 국 송신 중이거나 접속 직후 안정화 대기 — 몇 초 후 재시도
접속이 자주 자동으로 끊김일부 룸의 무통신 자동 이탈 정책 — 정상. PTT 한 번 눌렀다 떼면 재접속
