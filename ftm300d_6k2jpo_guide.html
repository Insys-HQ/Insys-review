개요

6K2JPO 국장님의 FTM-300D 무전기를 WIRES-X 포터블 디지털 노드로 운용하기 위한 케이블 연결부터 무전기 부팅 모드, 룸/노드 검색·접속까지 정리한 전용 가이드입니다. FTM-510D와 버튼 배치가 다르므로 반드시 이 문서 기준으로 진행하세요.

FTM-300D는 DIAL 노브 + [A/B] 키 중심 조작 체계이며, FUNC 노브 대신 F(SETUP) 키와 DIAL 노브를 사용합니다.
1. 준비물 및 케이블 연결
항목내용
연결 케이블WIRES-X 연결 케이블 킷 SCU-58 (또는 구형 SCU-40) — PC 연결 케이블 SCU-56/SCU-20 포함
USB 드라이버SCU-56/SCU-20용 Prolific 드라이버, 케이블을 PC에 꽂기 전에 반드시 먼저 설치
연결 위치무전기 뒷면 DATA 잭 ↔ PC USB 포트
PC 요구사항Windows 10/11, WIRES-X 소프트웨어 최신판(Ver.1.560 이상)
⚠️
케이블을 PC에 연결하기 전, 반드시 드라이버부터 설치하세요. 순서를 바꾸면 다른 드라이버가 잘못 잡힐 수 있습니다.
2. 무전기 부팅 모드
모드지원 범위켜는 방법화면 표시
일반 모드단독 교신버튼 조합 없이 전원 ON평소 VFO 화면
PDN 모드디지털 전용 인터넷 통신[D X] 키를 누른 채 전원 ON화면 하단 "WIRES-X PDN"
Portable HRI 모드디지털+아날로그 인터넷 통신[D X]+[GM] 키를 동시에 누른 채 전원 ON"WIRES-X" 표시
💡
한 번 특정 모드로 켠 뒤에는 그 모드가 기억됩니다. 이후 버튼 조합 없이 전원만 눌러도 같은 모드로 켜집니다. 일반 모드로 되돌리려면 마지막 사용한 조합을 한 번 더 누른 채 전원을 켭니다.
3. WIRES-X 소프트웨어 실행 및 최초 통신포트 설정
1
PC 먼저 켜기 → 케이블 연결 확인

이 단계에서 무전기는 아직 꺼둔 상태

2
바탕화면 "WIRES-X" 아이콘 실행
3
무전기를 PDN 또는 HRI 모드로 켜기

2번 표 참고

4
통신포트 설정 화면이 자동으로 뜨면(최초 실행 시) 무전기가 연결된 COM 포트를 선택 → OK

장치관리자에서 "Prolific USB-to-Serial Comm Port (COMxx)" 확인 가능

5
메인 화면에서 무전기 인식 및 ONLINE 상태 확인
4. 무전기 본체에서 룸/노드 검색·접속

4-1. 접속 시작

1
[D X] 키를 짧게 누름

"X" 아이콘이 점멸하며 접속 시작. PC와 정상 통신되면 점등으로 바뀌고 자국 노드 ID·도시명 표시

4-2. 목록에서 선택 접속

1
화면 하단 "SEARCH & DIRECT" 표시 상태에서 DIAL 노브로 선택 → DIAL 눌러 확정
2
카테고리 목록에서 DIAL 돌려 "ALL" 선택 → DIAL 확정

접속 가능한 룸·노드 전체 목록 표시

3
DIAL 돌려 원하는 룸/노드 선택 → DIAL 확정 (또는 선택 후 바로 PTT)

4-3. DTMF ID로 직접 접속 (노드 번호를 알 때 — 가장 빠름)

1
마이크 [#] 키를 길게 누름
2
마이크 숫자 키패드로 5자리 노드번호 입력
3
[#] 키를 다시 눌러 확정

4-4. 교신 및 종료

1
PTT로 교신
2
접속 해제 — 마이크 [*] 키 길게 누름
5. FTM-300D 노드 운용 중 조작키 요약
기능조작
운용모드 전환 (Access Point / Direct)[A/B] 키 짧게 누름
DG-ID 번호 설정[GM] 키 길게 누름 → DIAL 노브로 설정
주파수 설정 화면 복귀[D X] 키 길게 누름
송신출력 전환펑션메뉴 → [TXPWR] 또는 마이크 P4 키(기본설정)
접속 중인 룸/노드 절단마이크 [*] 키 길게 누름
스피커 뮤트 설정마이크 MUTE 키 짧게 누름
SQL 레벨 조절SQL 키 누른 채 DIAL 노브 회전
6. 자주 겪는 문제
증상원인/조치
[D X] 눌러도 X 아이콘이 안 뜨거나 바로 사라짐PC-무전기 통신 안 됨. "WIRES-X PDN" 표시가 점멸 중이면 케이블 재연결 후 재시도
룸/노드 접속 후 본체 버튼이 잘 안 먹음정상 동작. 접속 중엔 마이크 [#]/[*] 키만 계속 사용 가능
PTT 눌러도 송신 안 됨 ("TX Prohibit")다른 국 송신 중이거나 접속 직후 안정화 대기 — 몇 초 후 재시도
접속이 자주 자동으로 끊김일부 룸의 무통신 자동 이탈 정책 — 정상. PTT 한 번 눌렀다 떼면 재접속
