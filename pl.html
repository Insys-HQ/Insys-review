1. 기준 선택

입력자료 단위=업로드한 엑셀·캡처의 단위 / 화면 표시 단위=모든 탭의 금액 표기 방식. 저장은 항상 원 단위로 이루어진다.

2. 자료 업로드 엑셀 · 캡처화면

① 엑셀 파일
클릭하여 선택 또는 드래그
.xlsx / .xls / .csv
② 캡처 화면 붙여넣기
여기를 한 번 클릭한 뒤 Ctrl+V
(모바일은 길게 눌러 붙여넣기)
캡처를 파일로 저장했거나 모바일 사진첩에서 가져올 때 사용
설정 탭에 Claude API 키 입력 시 캡처화면 자동 판독이 가능하다.

기간 설정

Firebase 연동 insys-work / insys_pl

모든 손익 데이터는 Firestore insys_pl 컬렉션에 저장된다. 네트워크 장애 시 로컬에 임시 보관 후 상단 배지가 "오프라인"으로 바뀌며, 복구 후 전체 업로드로 동기화하면 된다.

Claude API 연동 선택

키가 없어도 규칙기반 분석 엔진으로 모든 시사점이 생성된다. 키 입력 시 캡처화면 판독과 심층 경영 조언이 추가된다.

계열사 관리

데이터 백업 · 복원

데이터는 이 브라우저에 저장된다. PC 교체·공유 시 반드시 JSON 백업할 것. Exchange 전환 후 Firestore 연동으로 교체 예정.
