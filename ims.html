시스템 메뉴 사용 방법
📋품목 관리
  1. 일괄 등록으로 품목 사전 입력
  2. 기준서 확인 주기 설정 (분기/반기)
  3. 주기 도래 시 자동 알림 표시
  4. 검사 시 드롭다운으로 선택만
  5. 확인 완료 시 자동 날짜 갱신
🔬① 측정의뢰
  1. 의뢰일 자동 (당일)
  2. 품목 선택 → 품목명 자동
  3. 의뢰 내용만 직접 입력
  4. "+ 의뢰 등록" 클릭
  5. 결과는 수입검사에서 입력
📦② 수입검사
  1. 품목 선택 (드롭다운)
  2. 기준서 확인 — 주기 도래 시만
  3. 외관·치수·판정 3개 선택
  4. 측정의뢰 결과 함께 입력
  5. 저장 → 일일보고 자동 반영
⚠️③ 부적합 관리
  1. "+ 부적합 등록" 또는 검사 연동
  2. 유형·수량·격리위치 입력
  3. 셰플러 SQM에 통보
  4. SQM 승인 후 처리 방법 확정
  5. 완료 시 "완료" 클릭
📋④ 일일 업무보고
  1. 보고 일자 자동 (당일)
  2. 검사·측정·부적합 자동 취합
  3. 특기사항만 직접 입력
  4. "인쇄" 클릭 → 보고서 출력
  5. 셰플러 SQM 요청사항 자동 표시
🎓교육 · 면담
  1. 부품 취급 지침 확인 (필독)
  2. 교육 실시 등록 (전달교육 포함)
  3. 월 1회 방문 면담 기록
  4. 분기 역량평가 (5개 항목)
  5. 품질 향상 활동 이력 관리
🎽업무지원
  1. 신청월·신청자 입력
  2. 재고·신청수량·사유 기입
  3. 안전화·근무복 사이즈 필수
  4. "+ 품목 추가" → "신청서 저장"
  5. 인시스 경영지원실 제출
🎯실행계획서

수입검사 업무 개선 6대 실행 항목을 담은 별도 문서입니다. (일회성 프로젝트 문서)

  • 업무일지 · ERP 모니터링
