시스템 메뉴 사용 방법
📋품목 관리
  1. 일괄 등록으로 품목 사전 입력
  2. 기준서 확인 주기 설정 (분기/반기)
  3. 주기 도래 시 자동 알림 표시
  4. 검사 시 드롭다운으로 선택만
  5. 확인 완료 시 자동 날짜 갱신
🔬① 측정의뢰
  1. 의뢰일·완료(예정)일 입력
  2. 품목번호·의뢰내용 기재
  3. 소요시간·결과·담당자 입력
  4. "+ 의뢰 등록" 클릭 저장
  5. 완료 시 "완료" 클릭
📦② 수입검사
  1. 품목 선택 (드롭다운)
  2. STEP1 주기 도래 시만 확인
  3. STEP2 체크리스트 + 검사 결과
  4. STEP3 판정 후 "저장"
  5. 이상 시 → SQM 보고 버튼
⚠️③ 부적합 관리
  1. "+ 부적합 등록" 또는 검사 연동
  2. 유형·수량·격리위치 입력
  3. 셰플러 SQM에 통보
  4. SQM 승인 후 처리 방법 확정
  5. 완료 시 "완료" 클릭
📋④ 일일 업무보고
  1. 보고 일자 자동 (당일)
  2. 검사·측정·부적합 자동 취합
  3. 특기사항만 직접 입력
  4. "인쇄" 클릭 → 보고서 출력
  5. 셰플러 SQM 요청사항 자동 표시
🎓교육 · 면담
  1. 부품 취급 지침 확인 (필독)
  2. 교육 실시 등록 (전달교육 포함)
  3. 월 1회 방문 면담 기록
  4. 분기 역량평가 (5개 항목)
  5. 품질 향상 활동 이력 관리
🎽업무지원
  1. 신청월·신청자 입력
  2. 재고·신청수량·사유 기입
  3. 안전화·근무복 사이즈 필수
  4. "+ 품목 추가" → "신청서 저장"
  5. 인시스 경영지원실 제출
🎯실행계획서

수입검사 업무 개선 6대 실행 항목을 담은 별도 문서입니다. (일회성 프로젝트 문서)

  • R&R 명확화 · RACI · 서명
  • 프로세스 표준화 · SOP
  • 품질 마인드 지침서
  • 업무일지 · ERP 모니터링
  • 시스템 환경 구축
