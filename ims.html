시스템 메뉴 사용 방법
📦입고검사
  1. 날짜·품목번호·품목명 입력
  2. 체크리스트 6항목 클릭 확인
  3. 외관·치수 결과 선택
  4. 최종 판정 선택 후 저장
  5. 불합격 시 부적합 등록
📋SAP 성적서 검토
  1. 품목번호·Rev.번호 입력
  2. 7개 항목 드롭다운 선택
  3. 이상 내용 특기사항 기재
  4. 저장 → Firebase 기록
  5. 없음·이상 → SQM팀 요청
🔬측정의뢰
  1. 의뢰일·완료예정일 입력
  2. 의뢰 내용 상세 기재
  3. 소요시간·결과·담당자 입력
  4. 의뢰 등록 클릭
  5. 완료 후 완료 버튼
⚠️부적합 관리
  1. + 부적합 등록 클릭
  2. 품목·유형·처리방법 선택
  3. 격리 위치 기재
  4. 처리 후 완료 버튼
  5. 대시보드 자동 알림 표시
🧤소모품 신청
  1. 신청 월·신청자 입력
  2. 품목별 재고·신청수량 기입
  3. 사이즈(안전화·근무복) 필수
  4. 매월 말일까지 제출
  5. 익월 초 지급 원칙
🎯실행 계획
  1. 5대 항목 중 해당 선택
  2. 태스크·담당자·목표일 입력
  3. 진행률(%) 주기적 업데이트
  4. 완료 시 완료 클릭
  5. 현황 공유 → 복사 후 공유
📁보고서
  1. 시작일·종료일 입력 후 조회
  2. 품목번호로 필터 가능
  3. 일일 보고서 출력 클릭
  4. 브라우저 인쇄 기능 활용
  5. 데이터 Firebase 영구 보관
💡이용 안내
  • 플로우차트 각 단계 클릭 → 메뉴 이동
  • 모든 데이터 Firebase 실시간 저장
  • 부적합 미처리 → 대시보드 알림
  • 분기 점검 결과 SQM팀 보고
  • 소모품 매월 말일 경영지원실 제출
