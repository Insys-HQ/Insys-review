시스템 메뉴 사용 방법
📦입고검사
  1. 검사일자·품목번호·품목명 입력
  2. 체크리스트 6항목 클릭하여 확인
  3. 외관·치수 결과 선택
  4. 최종 판정 선택 후 "저장"
  5. 불합격 시 → "부적합 등록" 클릭
📋SAP 성적서 검토
  1. 품목번호·Rev.번호·담당자 입력
  2. 7개 항목 드롭다운 선택
  3. 이상 내용 특기사항란 기재
  4. "검토 결과 저장" 클릭
  5. 없음/이상 → SQM팀 서면 요청
🔬측정의뢰
  1. 의뢰일·완료(예정)일 입력
  2. 품목번호·의뢰 내용 기재
  3. 소요시간·결과·담당자 입력
  4. "의뢰 등록" 클릭 → 저장
  5. 완료 시 테이블에서 "완료" 클릭
⚠️부적합 관리
  1. "+ 부적합 등록" 또는 검사 연동
  2. 유형·처리방법·격리위치 입력
  3. SQM팀 통보 후 처리 결정
  4. 완료 시 "완료" 클릭 → 이력 저장
  5. 미처리 건 → 대시보드 자동 알림
📦소모품 신청
  1. 신청월·신청자 입력 (매월 말일)
  2. 재고·신청수량·사유 기입
  3. 안전화·근무복 사이즈 필수 기재
  4. "신청서 제출" 또는 "출력"
  5. 경영지원실(총무) 제출 → 익월 지급
🎯실행 계획
  1. 5대 항목 중 해당 항목 선택
  2. 태스크명·담당자·목표일 입력
  3. 진행률·공유방법 설정
  4. 완료 시 "완료" → 진행률 자동 갱신
  5. "현황 공유" → 복사 후 메일·메신저
📁보고서
  1. 시작일·종료일 선택 후 "조회"
  2. 품목번호 입력 시 해당 품목만 필터
  3. "전체" 버튼으로 전체 이력 복원
  4. "일일 보고서 출력" → 인쇄 활용
  5. 이력은 Firebase에 영구 보관
💡사용 팁
  • 플로우차트 각 단계 클릭 → 해당 메뉴 이동
  • 모든 데이터 Firebase 실시간 저장
  • 모바일·PC 동시 사용 가능
  • 부적합·SAP이상 → 대시보드 자동 알림
  • 메뉴 카드 클릭으로도 이동 가능
⛔ Firebase 저장이 안 될 경우 — Firebase Console에서 보안 규칙을 아래와 같이 설정하세요:
{ "rules": { ".read": true, ".write": true } } 설정 경로: Firebase Console → insys-work → Realtime Database → 규칙(Rules)

🎯 실행 계획 (Action Plan)

수입검사 업무 효율화·품질 향상을 위한 5대 실행 항목 — 각 항목의 실제 도구를 직접 사용·작성·서명하고 문서를 관리합니다

① 검사원별 담당 업무 범위 매핑표 검사원을 등록하고 담당 업무 범위를 지정합니다
성명직급담당 라인담당 품목군백업서명관리
② RACI 책임 매트릭스 R=실행책임 · A=최종승인 · C=협의 · I=정보공유
업무 항목 검사 담당자검사 책임자품질책임자SQM팀경영지원실
③ R&R 공유 및 서명 확인 본인 R&R을 확인하고 전자서명으로 인지 확인
ℹ️ 아래 확인문을 읽고 서명하면 R&R 인지 확인이 기록됩니다.

본인은 셰플러 이천공장 수입검사 업무에 대한 담당 업무 범위, 권한 및 책임(R&R)을 확인하였으며, 아래 사항을 준수할 것을 확인합니다.

① 담당 품목의 검사기준서 최신 여부를 입고 시마다 확인한다.
② 기준서 이상 발견 시 즉시 SQM팀에 서면 요청하고 검사를 보류한다.
③ 모든 검사 결과를 SAP 및 일일 업무일지에 기록한다.
④ 부적합 발생 시 즉시 격리하고 관련 부서에 통보한다.
⑤ 본인 권한 범위를 벗어난 판정은 품질책임자에게 상신한다.
