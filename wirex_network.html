구성 목표 — 재난구호 하이브리드 무선통신망
기지국 A·B (거점 고정국) + 신월동 노드 (HRI-200 게이트웨이) + 긴급구호차량 (이동국) 을 WIRES-X 인터넷망으로 연결하고, 현장 봉사원의 C4FM 디지털 무전기·아날로그 FM 무전기·Zello PTT 앱이 모두 하나의 통신망에서 교신할 수 있게 한다. 아날로그 ↔ C4FM 상호 통신은 신월동 HRI-200 이 게이트웨이로 처리한다.

인터넷 / YAESU WIRES-X 서버

각 무선국(기지국 A·B, 신월동 노드, 긴급구호차량)에 설치된 WIRES-X 소프트웨어가 인터넷을 통해 YAESU WIRES-X 서버에 상시 접속하고, VoIP 방식으로 음성·데이터를 중계한다.
동일한 Room(룸)에 접속한 모든 노드는 RF 거리와 무관하게 실시간 교신 가능.

UDP 46100 (음성) UDP 46110 (제어) UDP 46112 UDP 46114 UDP 46120 UDP 46122

※ WIRES-X 소프트웨어 Ver.2.000 이상은 UPnP 자동 개방 가능.
구버전 노드와 혼용 시 라우터에서 위 6개 포트를 수동 포워딩.

  • 운용 모드: Digital Dual Rcv
  • → Voice CH + Preset Search CH 동시 수신 (1대로 운용)

  • Portable Digital Node (PDN) 모드로 실행
  • C4FM 디지털 신호 중계
  • WIRES-X 서버에 상시 접속 유지
  • 동일 Room 접속 시 신월동·기지국 B·구호차량과 연결

  • 4G/5G 인터넷 연결 → WIRES-X 서버 접속
  • 고정 IP 불필요 (동적 IP 지원)
📡 UV GP 안테나

신월동 WIRES-X 노드 — HRI-200 탑재 (전체망 게이트웨이)
Portable HRI 모드 · C4FM 디지털 ↔ 아날로그 FM 상호 변환
★ 이 국이 아날로그 ↔ C4FM 게이트웨이 역할 — HRI-200 은 전체망에서 1개만 필요
📻 FTM-510D
  • HRI-200에 CT-174 케이블로 연결 (PC 직결 아님)
  • 노드 모드 진입: [D/X]+[GM] 동시 누른 채 전원 ON
  • 디스플레이에 "HRI-200" 표시 확인
  • WIRES-X 소프트웨어 설정값이 트랜시버에 자동 반영
  • DG-ID: 00 설정 시 오픈 노드로 운용
🔌 HRI-200 (인터넷 연결 키트)
  • FTM-510D ← CT-174 (Mini-DIN 10pin ↔ 10pin) → HRI-200 RADIO 1
  • HRI-200 ← USB Type-B 케이블 → PC
  • USB 버스 전원으로 동작 (별도 DC 전원 불필요)
  • 2대 트랜시버 연결 시: RADIO 2에 추가 CT-174 연결 가능
  • 아날로그 트랜시버 연결 시: CT-175 사용 (6pin), 1,200bps 설정
💻 PC + WIRES-X 소프트웨어
  • 운용 모드: Portable HRI 모드 선택
  • C4FM 디지털 + 아날로그 FM 동시 지원
  • 아날로그 FM 사용자도 완전 지원 — 기기 교체 불필요
  • DTMF #55555 체크박스 활성화 필수 (Settings → General)
  • GM Auto Connect 활성화 권장
📡 UV GP 안테나 + 유심 라우터
  • 144 MHz / 430 MHz 듀얼밴드 고정 설치
  • 유심 라우터로 4G/5G 인터넷 연결
  • UDP 포트: UPnP 자동 또는 46114 / 46120 / 46122 수동 개방
  • Node Style: GM 설정 → Room도 GM 스타일 활성화
⇔
RF 무선 링크 — 144 / 430 MHz
구호차량 FTM-510D ↔ 현장 봉사원 무전기 간 RF 교신. 현장 RF 신호는 구호차량 FTM-510D → WIRES-X 경유 → 기지국·신월동에 중계됨. AMS(Auto Mode Select) 기능으로 C4FM 수신 시 자동 디지털 전환, 없으면 아날로그 FM 유지.

현장 단말 (봉사원)
C4FM · 아날로그 FM · Zello PTT
📻 YAESU C4FM 무전기 (FT-70D 등)
  • RF → 구호차량 FTM-510D 수신 → WIRES-X 경유 전체망 연결
  • AMS 자동 모드 선택: C4FM 수신 시 디지털 자동 전환
  • GM 멤버로 등록 시 그룹 내 위치 정보 공유
  • WIRES-X 노드 탐색: Preset Search CH에서 노드 자동 발견
📟 아날로그 FM 무전기 (기존 장비)
  • RF → 구호차량 FTM-510D 또는 신월동 HRI-200 경유
  • 신월동 HRI-200 게이트웨이에서 C4FM 디지털로 변환 중계
  • DTMF 톤으로 노드 원격 제어 가능 (기기 교체 불필요)
  • 데이터 포트 속도: 1,200bps (CT-175 연결 시)
📱 Zello PTT 앱 (스마트폰)
  • LTE → 인터넷 → Zello 서버 경유 PTT 통신
  • WIRES-X와 직접 연동 불가 (독자 프로토콜)
  • 권장 방법 ①: 지휘 차량에 Zello + 무전기 동시 운용 인원 배치
  • 권장 방법 ②: SVXLink / AllStarLink 게이트웨이 구축 (고급)

WIRES-X Room 운용 전략

Room 유형 선택이 재난통신 운용의 핵심이다. 평상시와 재난 발생 시 전환 시나리오를 미리 설정해 둔다.

🔓 Open Room
  • 누구나 접속 가능
  • 재난 발생 시 전환 운용
  • 외부 지원 무선국 수용
  • 아날로그 FM 국도 접속 허용
🔒 Closed Room
  • 등록 멤버만 접속 가능
  • 평상시 훈련·관리용
  • 봉사단원 사전 등록 관리
  • 보안 운용 · 혼선 차단
⭐ GM Room
  • 그룹 모니터링 전용
  • 멤버 위치 자동 감지
  • 통신 범위 외도 WIRES-X 경유 연결
  • 재난구호 최적 운용 방식
  • GM Auto Connect로 즉시 접속

권장 운용 시나리오

① 평상시: Closed Room — 봉사단원 등록·훈련·장비 점검
② 재난 발생: Open Room 전환 + GM Auto Connect 활성화 → 외부 지원 수용 + 구호차량 자동 접속
③ 철수 후: 다시 Closed Room 전환 · 활동 로그 저장

설치 및 설정 순서
  1. 1
    WIRES-X ID 등록 (사전 준비)
    YAESU WIRES-X 공식 웹사이트에서 각 무선국 트랜시버를 등록한다. 고유 Node ID / Room ID 가 발급되며, 이메일 인증까지 수일 소요될 수 있으므로 운용 전 미리 진행한다.
  2. 2
    신월동 HRI-200 물리 연결
    FTM-510D DATA 단자 → CT-174 (10pin↔10pin) → HRI-200 RADIO 1 단자 연결.
    HRI-200 USB 단자 → USB Type-B 케이블 → PC 연결. (USB 버스 전원으로 동작, 별도 전원 불필요)
    PC에서 HRI-200 드라이버 자동 설치 확인.
  3. 3
    기지국 A·B / 구호차량 USB 직결
    FTM-510D DATA 단자 → SCU-56 (또는 SCU-20) → PC USB 포트 직결.
    HRI-200 없이 PDN(Portable Digital Node) 모드로 동작.
  4. 4
    WIRES-X 소프트웨어 설치 및 설정
    각 PC에 WIRES-X 소프트웨어(Ver.2.000 이상) 설치.
    신월동: Node Style → Portable HRI · Room Style → GM 선택.
    기지국 A·B: Node Style → Digital Dual Rcv.
    구호차량: Node Style → GM · GM Auto Connect 체크.
    Settings → General → DTMF #55555 체크박스 활성화.
  5. 5
    FTM-510D 노드 모드 진입
    전 무선국 공통: [D/X] + [GM] 버튼을 동시에 누른 채 전원 ON.
    트랜시버 디스플레이에 "HRI-200" 표시되면 정상 진입.
    WIRES-X 소프트웨어 설정값(주파수·DG-ID·출력)이 트랜시버에 자동 반영됨.
  6. 6
    유심 라우터 인터넷 연결 확인
    각 무선국 유심 라우터로 인터넷 연결 확인.
    WIRES-X 소프트웨어가 UPnP 자동으로 포트를 개방하도록 라우터 설정.
    UPnP 미지원 라우터: UDP 포트 46100·46110·46112·46114·46120·46122 수동 포워딩.
  7. 7
    Room 개설 및 멤버 등록
    신월동 PC에서 WIRES-X 소프트웨어 → Room Activation → GM Room 개설.
    기지국 A·B·구호차량을 동일 Room ID로 접속 설정.
    봉사원 C4FM 무전기를 GM 멤버로 등록.
  8. 8
    통신 시험 및 최종 확인
    C4FM 무전기 ↔ 기지국 RF 교신 확인.
    아날로그 FM 무전기 → DTMF #55555 입력 → Room 접속 확인.
    구호차량 이동 중 WIRES-X 연결 유지 확인.
    GM 모드에서 멤버 위치 정보 표시 확인.
