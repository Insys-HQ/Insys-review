시스템 개요

YAESU FTM-510D + WIRES-X 재난구호 하이브리드 무선통신망

기지국 A·B(거점 고정국) + 신월동 노드(HRI-200 게이트웨이) + 긴급구호차량(이동국)을 WIRES-X 인터넷망으로 연결한다. 현장 봉사원의 C4FM 디지털 무전기·아날로그 FM 무전기·Zello PTT 앱이 모두 하나의 통신망에서 교신 가능하도록 구성. 아날로그 ↔ C4FM 상호 통신은 신월동 HRI-200이 게이트웨이로 처리한다.

🌐 인터넷 / YAESU WIRES-X 서버

각 무선국에 설치된 WIRES-X 소프트웨어가 인터넷을 통해 YAESU 서버에 상시 접속, VoIP로 음성·데이터 중계. 동일 Room 내 모든 노드는 RF 거리와 무관하게 실시간 교신 가능.

UDP 46100UDP 46110UDP 46112 UDP 46114UDP 46120UDP 46122

※ WIRES-X SW Ver.2.000 이상 UPnP 자동 개방. 구버전 혼용 시 라우터 수동 포워딩 필요.

DTMF 원격 제어 명령어

아날로그 FM 무전기 사용자가 DTMF 톤으로 HRI-200 노드를 원격 제어. 사전 설정: WIRES-X SW → Settings → General → DTMF #55555 체크박스 활성화 필수.

#55555
지정 Room 자동 접속
미리 지정된 기지국 Room에 즉시 연결. 긴급 시 우선 사용.
#66666
노드 상태 조회
현재 접속 여부·Room 정보를 음성으로 회신.
#99999
접속 해제
현재 Room에서 분리. 채널을 비워 타 사용자 사용 가능.
*
접속 해제 (단축)
#99999 와 동일 기능. 간편 단축 코드.

WIRES-X Room 운용 전략

Room 유형 선택이 재난통신 운용의 핵심. 평상시와 재난 발생 시 전환 시나리오를 미리 설정해 둔다.

🔓 Open Room
  • 누구나 접속 가능
  • 재난 발생 시 전환 운용
  • 외부 지원 무선국 수용
  • 아날로그 FM 국도 접속 허용
🔒 Closed Room
  • 등록 멤버만 접속 가능
  • 평상시 훈련·관리용
  • 봉사단원 사전 등록 관리
  • 보안 운용 · 혼선 차단
⭐ GM Room
  • 그룹 모니터링 전용
  • 멤버 위치 자동 감지
  • 통신 범위 외도 WIRES-X 경유 연결
  • 재난구호 최적 운용 방식
  • GM Auto Connect 즉시 접속

권장 운용 시나리오
① 평상시: Closed Room — 봉사단원 등록·훈련·장비 점검
② 재난 발생: Open Room 전환 + GM Auto Connect → 외부 지원 수용 + 구호차량 자동 접속
③ 철수 후: Closed Room 전환 · 활동 로그 저장

설치 및 설정 순서
1
WIRES-X ID 등록 (사전 준비)
YAESU WIRES-X 공식 사이트에서 각 무선국 트랜시버 등록. Node ID / Room ID 발급 (이메일 인증, 수일 소요). 운용 전 미리 진행.
2
신월동 HRI-200 물리 연결
FTM-510D → CT-174 → HRI-200 RADIO 1. HRI-200 → USB Type-B → PC. 드라이버 자동 설치 확인.
3
기지국 A·B / 구호차량 USB 직결
FTM-510D → SCU-56 → PC USB 포트. HRI-200 없이 PDN 모드 동작.
4
WIRES-X SW 설치 및 모드 설정
신월동: Portable HRI + GM Room. 기지국 A·B: Digital Dual Rcv. 구호차량: GM + Auto Connect. DTMF #55555 활성화.
5
FTM-510D 노드 모드 진입
전 무선국: [D/X]+[GM] 동시 누른 채 전원 ON → 디스플레이 "HRI-200" 확인. SW 설정값 자동 반영.
6
라우터 포트 설정
UPnP 자동 확인. 미지원 시 UDP 46100·46110·46112·46114·46120·46122 수동 포워딩.
7
Room 개설 및 멤버 등록
신월동 PC → Room Activation → GM Room 개설. 전 무선국 동일 Room ID 접속. 봉사원 C4FM 무전기 GM 멤버 등록.
8
통신 시험 및 최종 확인
C4FM ↔ 기지국 RF 교신 확인. 아날로그 → DTMF #55555 → Room 접속 확인. 구호차량 이동 중 연결 유지 확인.
