개요

이 문서는 야에스 FTM-510D(일본 내수 사양) 무전기에 다른 회원(6K2JPO)이 만든 메모리 채널 파일을 ADMS-18 프로그램으로 설치하는 과정에서 발생한 통신 오류와 그 해결 과정을 정리한 실전 기록입니다. 케이블·소프트웨어·SD카드 세 갈래로 원인을 좁혀나간 순서를 그대로 담았으므로, 동일한 증상을 겪는 다른 회원들의 시간을 절약하는 데 목적이 있습니다.

핵심 결론: 일본 현지에서 구입한 FTM-510D는 반드시 일본어판 ADMS-18을 사용해야 합니다. 영문판(해외 수출용 FTM-510DR/DE 대상)은 케이블·드라이버·설정이 전부 정상이어도 CLONE 통신 자체가 프로토콜 불일치로 실패합니다.
증상 → 원인 → 해결 요약표
증상원인해결
ADMS-18 CLONE 통신 시 "Searching..." 후 1~2초 만에 Error영문판 ADMS-18과 일본 내수 사양 무전기 간 프로토콜 비호환일본어판 ADMS-18로 재설치

SD CARD 메뉴(BACKUP/FORMAT)가 모두 비활성화128GB(microSDXC) 카드는 FTM-510D 지원 규격 초과 (지원 규격: 2GB~32GB microSD/microSDHC)32GB 이하 카드로 교체, 무전기 자체 FORMAT 메뉴로 포맷

1. 준비물
항목내용
ADMS-18 (일본어판)야에스 일본 공식 사이트 connect.yaesu.com → FTM-510D ASP 시리즈 페이지 → "메모리 편집 소프트 ADMS-18 다운로드"
PL2303 USB 드라이버SCU-56/SCU-58 케이블용, 영문판·일본어판 공통 사용 (재설치 불필요)
SCU-56 DATA 케이블무전기 DATA 잭 ↔ PC USB 연결용 (SCU-58 킷에 포함)
microSD 카드 (대안 경로)32GB 이하, microSD/microSDHC 규격만 지원 (SDXC 128GB 이상 불가)
⚠️
일본 현지 구입 모델(FTM-510D)과 해외 수출 사양(FTM-510DR/DE)은 ADMS-18 소프트웨어가 서로 호환되지 않습니다. 반드시 무전기 구입 국가 사양에 맞는 버전을 사용하세요.
2. ADMS-18 설치 (일본어판)
1
기존 영문판 ADMS-18 완전 제거

제어판 → 프로그램 제거 → 기존 FTM-510D ADMS-18 삭제

2
일본어판 다운로드 및 설치

connect.yaesu.com → FTM-510D ASP 시리즈 페이지에서 다운로드 → setup.exe 실행 → 관리자 권한으로 설치

3
PL2303 드라이버 확인

이미 설치되어 있다면 재설치 불필요. 장치관리자 → 포트(COM & LPT) → "Prolific USB-to-Serial Comm Port" 확인

4
SCU-56 케이블로 무전기와 PC 연결
3. 데이터 취득 (무전기 → PC) — 순서 주의
🚨
순서를 반대로 하면 에러가 납니다. 데이터 취득은 PC 먼저 → 무전기 나중 순서입니다.
1
무전기를 일반 모드로 켠 상태에서 대기
2
ADMS-18 상단 通信(C) → FTM-510Dからデータ取得(G) 클릭
3
PC 팝업창에서 먼저 OK 클릭
4
무전기 FUNC 노브 길게 눌러 SETUP → 118 クローン送信(This→Other) 선택 → FUNC 확정
5
바그래프 표시되며 전송 시작 → "Completed" 확인
💡
실무에서는 4번(무전기 조작)을 먼저 하고 3번(PC OK)을 나중에 눌러도 진행은 되나, 매뉴얼 권장 순서(PC 먼저)를 지키는 것이 가장 안정적입니다.
4. 데이터 송신 (PC → 무전기) — 반대 순서
🚨
송신은 취득과 정반대 순서입니다 — 무전기 먼저 → PC 나중.
1
ADMS-18에서 전송할 파일이 열려있는 상태 확인 (6K2JPO 파일을 열어 콜사인 등 개인정보 수정 완료 후)
2
ADMS-18 상단 通信(C) → FTM-510Dへデータ送信(S) 클릭
3
무전기 FUNC 노브 길게 눌러 SETUP → 119 クローン受信(Other→This) 선택 → FUNC 확정 (먼저)
4
PC 팝업창에서 OK 클릭 (나중)
5
바그래프 표시되며 전송 시작 → "Completed" 확인 → 무전기 자동 재시작
5. 타인 파일 적용 전 개인정보 점검 체크리스트

다른 회원의 .FTM510D 파일을 받아 적용할 때는, Set Mode(セットモード設定) 화면의 아래 항목들을 반드시 본인 것으로 확인/수정 후 전송하세요.

탭확인 항목비고
GM WIRES-XCallsign (GM)본인 콜사인으로 반드시 수정
GM WIRES-XWIRES 周波数 (VHF/UHF 프리셋)자주 쓰는 룸/채널 주파수로 조정 권장
APRSコールサイン(APRS)보통 회색 비활성 — 남아있는지만 확인
APRS BeaconBeacon Ringer Call, Beacon 상태 텍스트타인 정보 잔여 여부 확인
基本設定言語設定무전기 LCD 표시 언어 (일본어/영어) — 취향껏 선택
⚠️
전송 전, 반드시 내 현재 설정을 Get Data로 먼저 백업(파일 저장)해두세요. 실수로 덮어쓴 경우 복구할 방법이 없습니다.
6. 대안 경로 — microSD 카드 전송

케이블 통신이 계속 실패할 경우, ADMS-18 매뉴얼이 공식적으로 안내하는 대안입니다. CLONE 프로토콜 통신 자체를 우회합니다.

1
32GB 이하 microSD 카드 준비, 무전기 자체 FORMAT 메뉴로 포맷

SETUP → SD CARD → 108 FORMAT (PC에서 포맷하지 말고 무전기에서 직접 포맷 권장)

2
무전기 SETUP → SD CARD → 106 BACKUP → SD に書き込み (WRITE TO SD)

내 현재 설정을 먼저 SD카드에 백업

3
ADMS-18 → 通信(C) → SD カードからデータ取得(D)

PC 카드리더로 SD카드 내용 불러오기

4
File → 開く(O)로 받은 파일 열고, 통신 → SD カードへデータ送信(U)

편집한 데이터를 SD카드용 파일로 저장

5
SD카드를 무전기에 삽입 → SETUP → SD CARD → 106 BACKUP → SD から読み込み

무전기에 설치 완료

7. 트러블슈팅 — 실전 확인 순서
순서확인 항목
1장치관리자에서 Prolific COM 포트 정상 인식 여부
2WIRES-X 소프트웨어가 트레이 아이콘까지 완전 종료됐는지
3ADMS-18의 COM Port Setting이 실제 포트 번호와 일치하는지 (Determine 버튼으로 자동 확인 가능)
4무전기 SETUP → 69(또는 68) COM PORT의 SPEED가 ADMS-18과 일치하는지
5DATA 케이블이 무전기 뒷면 DATA 잭에 완전히 결합됐는지
6PC OK/무전기 FUNC 확정 순서가 방향(취득/송신)에 맞게 지켜졌는지
7위 모두 정상인데도 반복 실패 시 → ADMS-18 언어판(영문/일본어)과 무전기 사양(내수/수출)이 일치하는지 최우선 확인
