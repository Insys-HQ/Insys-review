리그 설정 방법 (FTM-510D 기준)
STEP 1
WIRES-X 소프트웨어 설정
  • PC에서 WIRES-X 소프트웨어 실행
  • 운용 로컬 주파수 지정 (예: 430.XX MHz)
  • 모드: FM 고정 (AMS 비활성화)
  • 노드 이름 및 콜사인 6K2JPO 확인
  • HRI-200 연결 상태 정상 확인 (녹색 표시)
STEP 2
FTM-510D 리그 설정
  • 로컬 주파수로 VFO 설정
  • AMS 해제 → FM 모드 고정
  • 스켈치: 캐리어 스켈치 권장
    (CTCSS/DCS 없이 운용)
  • WIRES-X 버튼으로 노드 모드 진입
  • 소프트웨어와 주파수 일치 확인
STEP 3
룸 연결 (WIRES-X 소프트웨어)
  • 소프트웨어에서 Room 07517 검색
  • 또는 DTMF: A 07517 #
  • 연결 완료 시 노드 화면에 룸명 표시
  • 연결 유지 확인 후 교신 대기
  • 해제: A 00000 #
STEP 4
인터넷 / HRI-200 점검
  • HRI-200 연결 PC 인터넷 상시 연결 필수
  • 방화벽: WIRES-X 포트 허용 확인
  • HRI-200 전원 ON 상태 확인
  • 소프트웨어 재시작 시 재연결 필요할 수 있음
