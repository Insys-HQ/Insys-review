케이블구간규격적용 노드
CT-174
HRI-200 박스 동봉
 FTM-510D DATA ↔ HRI-200 RADIO 1 Mini-DIN 10pin ↔ 10pin DS0ARC만 해당
USB Type-A to B
HRI-200 박스 동봉
 HRI-200 ↔ PC USB-A USB 2.0 이상 DS0ARC만 해당
SCU-56 / SCU-20
별도 구매
 FTM-510D DATA ↔ PC USB Mini-DIN 10pin → USB HL0FRC · DS0ARC/M
SCU-58
별도 구매
 FTM-510D DATA ↔ PC USB (COM3) Mini-DIN 10pin → USB HL2TLS
동축 케이블
PL-259 커넥터
 FTM-510D ANT ↔ 안테나 RG-8X 또는 5D-FB · 50Ω 전체 노드 공통
⚠️ 주의  CT-174는 HRI-200 전용 케이블로 PDN 노드(HL0FRC·DS0ARC/M·HL2TLS)에는 불필요. SCU-58은 HL2TLS에서 COM3으로 인식 확인됨.
